## Overall judgment

This version is improved, but it is still not compact enough from a reviewer/layout perspective. The main issue is not that every page is loose; rather, the density is uneven. Pages 8, 9, 12, and 13 are mostly acceptable, while pages 10, 11, and 15 still give a visibly unbalanced impression.

The most serious layout problem is still Fig. 4. It occupies an almost isolated page, leaving large blank regions. This makes the manuscript look less polished even though the figure content itself is now closer to the manuscript argument.

## Page-by-page comments

### Page 8

Acceptable. Fig. 3 and Table 2 are placed reasonably, and the remaining text fills the page. The figure labels are now cleaner and no longer show the earlier internal experimental naming problem.

### Page 9

Mostly acceptable but slightly table-heavy. Tables 3 and 4 are stacked at the top, and the text resumes underneath. This is compact enough, but the transition between speed sensitivity and hairpin discussion still feels a little abrupt.

### Page 10

Still visually heavy. Tables 5, 6, 7, and 8 are stacked in one vertical block. This is content-dense, but aesthetically it reads like a table wall. It is compact in space usage, but not elegant.

Suggested adjustment: keep only the two most important tables in the main text and move the weakest diagnostic table to supplementary material, or reduce the vertical spacing before/after captions.

### Page 11

Not compact. Fig. 4 remains the clearest layout defect. The figure is effectively isolated, with large unused space on the right and bottom. This page should be fixed before submission.

Best adjustment: convert Fig. 4 into a full-width two-column figure using a 2 x 2 arrangement, or move it so that it appears at the top of a page where both columns can be filled by surrounding text. If the journal format permits, `figure*` is preferable here.

### Page 12

Acceptable. Fig. 5 and Fig. 6 are dense but readable. Fig. 5 still has some crowded axis-label areas, but it is no longer the main layout problem.

### Page 13

Acceptable as text flow. Section 5.7, the discussion, conclusion, and acknowledgement are readable. The bottom area is somewhat empty, but this is less severe than the Fig. 4 page because it occurs near the end of the main text.

### Pages 14-15

References are not compact. Page 14 is full, but page 15 contains only the final reference entry and leaves nearly the entire page blank. This makes the final manuscript look unfinished or loosely packed.

Suggested adjustment: compress the bibliography style if allowed, remove duplicated DOI/URL redundancy if the target style permits, or reduce unnecessary line breaks in reference entries. Several entries still show DOI and URL on separate lines, which expands the reference section.

## Priority fixes

1. Fix Fig. 4 placement first. This is the most visible remaining layout issue.
2. Reduce the stacked-table impression on page 10. Consider moving one secondary table to supplementary material.
3. Compact the bibliography so page 15 does not contain only one reference.
4. Keep pages 8, 12, and 13 mostly unchanged; they are not the main problem.

## Final recommendation

The content fixes appear mostly in the right direction, but the manuscript still needs one more layout pass before it looks submission-ready. I would not call this version fully compact yet. The next revision should target page balance rather than adding more content edits.
