# Koopman线性专家停止后的解决方案

## 1. 停止结论

本轮按`koopman.md`执行到K2.10后停止。K2.0新数据、K2.1线性可辨识性、K2.2状态变量门和K2.3控制输入门均通过；三线性专家的soft gate没有通过GK2分层预测价值门。因此当前**不允许**继续bilinear、MF-IK、IRSP或稳定性证书，也不能把三专家门控写成论文贡献。

这里的失败不是仿真发散：global、oracle、hard、soft及external的20步输出全部有限。失败是相对最佳固定线性模型没有形成稳定预测优势。

## 2. 已核实证据

### 2.1 数据与单模型线性门

- 新数据共120条完整轨迹：train/validation/test/external=`70/15/15/20`，五类场景各24条，同一轨迹窗口不跨集合。
- 最大连接力`2672.43 N`，最大张开代理`791.72 N`，共同ICR残差峰值`1.48e-14 m/s`；这些是当前仿真模型内数值，不是实物撕裂阈值。
- S3+U1 raw linear独立test的10–20步状态/连接力/张开NRMSE为`0.03710/0.21580/0.43825`。
- S3+U1 lifted linear对应指标为`0.03112/0.20216/0.40668`；相对raw在独立test改善，但external张开误差没有同步改善。
- S3相对S2的逐轨迹差值（候选减基线）95% CI：连接力`[-0.4713,-0.1650]`，张开`[-0.3715,-0.1773]`，支持连接形变/相对速度进入状态。
- U0阵列聚合输入相对U1四车实际输入显著恶化状态和连接力；U2命令输入也比U1差。U3增加分配元数据能改善状态，但张开没有可靠改善，所以主物理输入仍保持U1。
- 固定非训练lift下，S5与S3使用相同输入和相同受力监督读出，数学上不能形成真正独立的S4/S5比较；不得把两份同构计算包装成消融证据。

### 2.2 三线性专家门

训练标签样本量为E-L/E-C/E-T=`66017/44086/9142`，不是少数专家没有样本。validation选择的门控参数为`tau=0.15`、无额外平滑。

独立test的10–20步NRMSE：

| 方法 | 状态 | 连接力 | 张开 |
|---|---:|---:|---:|
| 固定全局linear | 0.02702 | 0.16024 | 0.38398 |
| 弱标签oracle | 0.02352 | 0.16962 | 0.37023 |
| hard gate | 0.02453 | 0.17056 | 0.35910 |
| soft gate | 0.02919 | 0.16567 | 0.35952 |

事实边界：这里的“oracle”使用test真实弱物理标签，只是不可部署比较器；弱标签不是逐步最小误差选择，所以结果也证明它不是数学上界。

- soft相对global的分层综合误差变化：E-L恶化`35.61%`，E-C恶化`17.16%`，E-T改善`18.16%`。只改善一个分层，且另两个恶化超过5%，分层门失败。
- soft相对global的逐轨迹连接力NRMSE差值为`+0.02462`，95% CI=`[+0.01128,+0.03630]`，方向明确为更差；状态和张开CI跨0，不能宣称改善。
- external上soft相对global：状态由`0.04750`恶化到`0.05643`，连接力由`0.33576`恶化到`0.36347`，张开由`0.50122`恶化到`0.55322`。
- E-T并非完全无效：soft相对noTransition在过渡段的综合误差、连接力p95和张开p95分别降低`53.11%/60.33%/58.28%`。
- soft平均占用为`[0.5563,0.3582,0.0856]`，三个工况的主权重排序正确；但validation选出的`tau=0.15`使平均有效专家数只有`1.123`，门控已接近hard switch。

## 3. 原因判断

以下是待验证解释，不是既成事实：

1. 三个独立局部转移矩阵在各自一步样本上拟合，20步递推跨工况时缺少共同基模型约束；这能解释E-T局部有效而E-L/E-C长时域变差。
2. S4把当前力和力变化率重复放入状态，局部专家可能依赖强相关派生量，降低external参数失配下的稳健性。
3. E-T用未滤波的因果`dot(Q)`阈值标注，可能把连接器高频数值变化当成物理模式切换；不过标签数量和对角权重均正常，不能仅靠调阈值宣称问题已解决。
4. 当前fixed quadratic lift没有通过多步和受力联合损失学习；局部矩阵增加的方差可能大于工况分解带来的偏差收益。

## 4. 推荐解决顺序

### 方案A：论文当前可用的保守路线（推荐）

保留`S3/S4 + U1`的单一lifted linear AKE作为预测器，把论文主线收缩为“通信质量感知的受力约束MPC”。删除三专家、bilinear和IRSP强主张。此路线已有独立test、external和受力输出证据，风险最低。

### 方案B：只救E-T，不重做三套完整专家

1. 共享全局线性转移矩阵；E-L与E-C不再各自替换整个转移矩阵。
2. 仅为E-T训练有范数上界的小残差`Delta f_T`，门控只在过渡段逐渐启用残差。
3. 对`Q_FR/Q_LR`使用预先冻结截止频率的因果低通后再做后向差分；必须同时报告相位滞后。
4. 用validation选择残差范数和门控平滑，不读取test；重新使用同一test只会变成开发集，因此最终结论需另建确认集。
5. 先要求global+E-T在E-T段保持当前收益，并保证E-L/E-C不恶化超过5%；不通过即永久删除专家路线。

### 方案C：完成真正的S4/S5比较后再决定模型状态

实现共享可训练lift，固定lift总维数和训练预算：

- S4：形变/相对速度/显式力均进入编码器；
- S5：编码器只读S3，四点力、张开和因果力变化率作为多任务监督输出；
- 两者使用相同20步rollout、相同force loss、相同参数量级和整轨迹划分。

若S4只改善训练误差或external继续恶化，选择更紧凑的S5。没有这一步，不能冻结“显式力必须入状态”的论文结论。

### 方案D：何时才允许重新考虑MF-IK

只有方案B或C在新的确认集上同时满足以下条件才恢复：

- 至少两个物理分层10–20步主要NRMSE改善，第三层恶化不超过5%；
- 连接力或张开主要指标改善且逐轨迹95% CI不跨0；
- external不同时恶化状态、连接力和张开；
- 门控不是近似hard switch，且没有专家塌缩；
- 随后再做plant有限差分Jacobian方向一致性。

在此之前继续增加bilinear、IRSP或证书只会把“线性门控没有预测价值”的问题复杂化，不能形成支撑审稿回复的证据。

## 5. 样本与统计限制

当前独立test只有15条轨迹，满足本轮探索门，但不满足计划K5的最终`paired n>=20`论文统计要求。若采用方案B/C重新开发，现有test已被查看，应转作开发证据，并额外生成冻结seed的确认集；不能反复用这15条轨迹调门控后仍称其为独立test。
