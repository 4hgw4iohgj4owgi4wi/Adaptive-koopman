# Koopman方法对比最终报告

> 实验状态：T0–T6已执行；E0–E8为一次性confirm，E9仅为development诊断。所有“优势”判断仍使用预注册的8%改善、paired 95% CI、关键量不恶化、非发散、实时和Holm校正联合门，未因结果不理想而放宽。

## 1. 最终结论

- 没有一个复杂Koopman在任何场景通过全部优势门，离线候选集合为`{}`。
- 综合confirm `J_pred`最低的是K0 raw linear：`0.12514`；K1 fixed lifted linear为`0.13284`。在当前数据域，K0是最低误差和最低成本的默认预测器。
- K1并非处处劣于K0：E5回头弯中K1明显更好，K0相对K1恶化`30.7%`；K1的全局货物拉伸方向准确率也更高（`0.6693` vs `0.6276`）。因此需要回头弯/受力方向稳健性时，K1仍是更保守的选择。
- K2确实使用了输入—状态乘积，但这种机理利用没有形成稳定的总体收益。K2在E0 confirm相对K1降低`J_pred 10.8%`，却因development发散率由`0`增至`0.352%`且Holm校正`p=0.165`而不能标记为优势。
- T5按冻结门记为`not_applicable_no_offline_candidate`。没有相同MPC闭环结果，不能声称任何方法改善了跟踪、连接力或货物拉伸载荷。

## 2. 各工况适用结论

下表“最低观测值”是事实描述，不等同于通过联合优势门。

| 场景 | confirm最低观测方法 | 相对K1 | 结论 |
|---|---|---:|---|
| E0 直线匀速 | K2 | `+10.8%` | 有局部精度信号，但发散率和Holm门未过；部署仍选K1或更简单的K0。 |
| E1 直线加速/制动 | K0 | `+25.0%` | raw linear最合适；双线性和神经lift明显恶化。 |
| E2 稳态弯 | K0 | `+12.9%` | 当前曲率域不需要复杂lift；K2相对K1恶化`6.7%`。 |
| E3 正反阶跃 | K0 | `+10.1%` | K0最低；K5-linear未改善过渡递推，K2在confirm反而恶化`121.5%`。 |
| E4 单移线 | K0 | `+2.9%` | 与K1落在3%等价带内，按复杂度优先K0。 |
| E5 回头弯 | K1 | 基准最佳 | K1明确优于K0及所有复杂方法，是K1最有价值的场景。 |
| E6 连接器方向激励 | K1/K0近似等价 | K0 `-0.3%` | 两个简单模型等价；复杂双线性没有带来四点力方向收益。 |
| E7 参数外推 | K0/K1近似等价 | K0 `+3.0%` | 接近等价边界；可训练lift没有外推优势。 |
| E8 网络退化 | K0 | `+8.6%` | 同一观测管理器下K0观测误差最低；没有复杂模型通过网络鲁棒性门。 |
| E9 可辨识性激励 | K5-linear（development） | `+30.0%` | 仅诊断信号，无独立confirm；不能授予E9优势标签。K2为`+21.5%`。 |

| K1 fixed lifted | `0.13284` | `13,857` | `0.183 ms` | 回头弯最好，物理Q代数一致性和方向判断在简单模型中更好 | E1/E2/E3/E8不如K0 |

## 4. 双线性机理与数据量证据

- K2/K3双线性贡献比`r_bil`中位数分别为`0.23/0.25`，90%分位为`0.47/0.61`，不是“训练后被忽略”的零项。
- Development-test消融的macro `J_pred`：K2完整`0.17`、置零`0.50`、轨迹内打乱配对`0.34`；K3完整`0.33`、置零`0.74`、打乱`0.38`。这支持“模型利用了正确的输入—状态配对”，但不支持“因此比简单模型更好”。
- 原数据完整双线性有效秩为`827/837`。加入E9-train后仍为`827/837`，条件数由`9.490×10^7`变为`9.550×10^7`，E9没有修复剩余共线方向。
- 10%训练数据下，K2/K3会出现从个位到`10^6`级的seed依赖递推误差；K0/K1仍主要位于`0.12–0.45`。复杂双线性的主要短板是样本效率和数值稳健性，而不只是参数数量。

## 5. 受力与物理边界

- Confirm 140条全部通过有限性、共同ICR和15 kN极限门；最大共同ICR残差`1.48×10^-14 m/s`，最大连接力`1.155 kN`。
- 原train中“任一点达到额定力50%”的强受力样本占比为`0%`。本结论只覆盖当前普通接触/操纵载荷域，不能外推到12 kN额定力附近。
- K0/K1的四点力推导Q与直接Q输出代数残差仅`2.12×10^-7 N / 1.79×10^-7 N`；K2、K3、K4分别为`2.63×10^5 N`、`4.19×10^3 N`、`11.49 N`，说明复杂模型的受力输出内部一致性更差。
- 18维监督合同只包含货物侧四点力，无法用两个独立预测量检验作用—反作用。结果中明确记录`not_identifiable_from_payload-side-only_18D_output`，没有把同一力取负后冒充证据。
