## 1. 最新结果与重新设计结论

### 1.1 术语统一：`opening`改称“货物拉伸载荷”

代码和JSON中的历史字段`opening`不是连接器张开距离，也不是货物裂缝宽度，而是由四个连接点受力构造的**货物拉伸载荷**，单位为N。四点顺序为`FL/FR/RL/RR`：

```text
Q_FR = 0.5 * [(Fx_FL + Fx_FR) - (Fx_RL + Fx_RR)]
Q_LR = 0.5 * [(Fy_FL + Fy_RL) - (Fy_FR + Fy_RR)]
```

- `Q_FR`：货物前后向拉伸载荷；
- `Q_LR`：货物左右向拉伸载荷；
- 正值表示当前坐标约定下的拉伸趋势，负值表示反向压缩趋势；
- 图表中的绝对值、峰值和P99表示差动力幅值；
- `opening NRMSE`应解释为**货物拉伸载荷预测误差**，不是货物实际张开程度或撕裂概率。

为保持既有脚本、结果JSON和checkpoint兼容，代码字段名仍保留`opening`；从本文件起，中文正文和图题统一使用“货物拉伸载荷”。在没有材料强度、截面积、疲劳和三维载荷模型前，不把该指标直接称为“撕裂力”。

### 1.4 推测，不作为结论

以下解释只决定待验证实验，不写入论文结论：

1. 固定lift用闭式正则最小二乘，优化问题稳定；K3同时训练encoder、转移和decoder，长时递推误差与可辨识性负担更大。
2. S4的72维输入在总lift维数96下只剩24个学习observable，显式力、货物拉伸载荷、力变化率、mask和AoI可能挤占有效容量。
3. K3 clean训练中mask恒为1、AoI恒为0，因此压力失败更可能是训练分布缺失，而不是“mask形式本身无效”。
4. 固定S4的clean优势可能在AoI/丢包下消失；K3的trainable S4压力结果不能替代fixed S4压力结果。

### 1.5 K4的最终判断

K4已经验证“固定lift上的基线锚定低秩多步修正”。它相对全量refit更好，也改善连接力和货物拉伸载荷预测，但以状态误差恶化`21.70%`为代价，综合改善不足预注册门。因此当前结论不是“继续微调M3”，而是停止本轮候选并回到M1 fixed S5-operational。

若以后重启M3，必须建立新的开发/确认划分，重新预注册残差参数化、状态—受力损失权重和supervisor最小驻留；不得继续使用本轮validation追门。

## 2. K4回答的三个问题

1. **状态合同问题**：fixed S4的clean收益能否覆盖实时力测量的AoI、丢包和单点失效成本？若不能，是否应固定使用S5-operational？
2. **20步方法问题**：在不改变固定lift、不引入三专家和bilinear的情况下，小范围多步修正能否稳定击败fixed linear？
3. **控制价值问题**：离线10–20步改善能否在同一四车—货物plant上降低跟踪误差或内部撕裂代理，同时不增加峰值力、不可行率和实时开销？

三个问题必须顺序回答。前一门失败，后续对应路线停止。

## 4. 公平模型矩阵

### 4.1 模型定义

| 编号 | 模型 | 作用 |
|---|---|---|
| `M0-raw` | raw-state linear，S5-operational+U1 | 无lift下界 |
| `M1-fixed` | K2固定二次lifted linear，S5-operational+U1 | 首要基线与最终fallback |
| `M1F-fixed-S4` | K2固定二次lifted linear，S4+U1 | clean力传感增强对照，不默认可部署 |
| `M2-full` | 固定lift、全部A/B重新用20步损失优化 | 诊断“多步目标是否有用”；参数自由度大，不默认作为贡献 |
| `M3-anchor` | 固定lift、围绕M1做低秩小范数多步修正 | K4唯一新方法候选 |
| `M4-K3` | K3 trainable S5的已冻结结果 | 历史负对照，只读复用，不重新训练 |

M0/M1/M1F直接复算既有模型。M2/M3必须使用相同状态、输入、训练轨迹、归一化、20步teacher-free rollout和输出指标。

### 4.2 固定lift

继续使用K2已核实的固定映射：

```text
phi0(x) = [1, x_norm, clip(x_norm)^2]
```

不新增神经encoder，不改变输入维度，不借由额外历史窗口获得不公平信息。

### 4.3 基线锚定低秩修正

M1为：

```text
z(k+1) = A0 z(k) + B0 u(k)
y(k)   = C0 z(k)
```

M3为：

```text
A = A0 + LA RA^T
B = B0 + LB RB^T
CF = CF0 + LF RF^T
```

其中：

- `rank(A修正) ∈ {2,4,8}`；B和受力读出修正秩不超过A修正秩；
- `||ΔA||F/||A0||F`投影上限为`{0.5%,1%,2%}`；B和CF使用同一相对上限；
- 所有修正参数初始化为使模型输出严格等于M1；具体采用“左因子全零、右因子非零正交”的确定性初始化，`R_A/R_B/R_F`分别由预注册seed `74411/74412/74413`生成并做QR正交化，禁止左右因子同时置零导致零梯度；
- 每次更新后执行范数投影，保存投影前后范数；
- 物理状态直通和作用—反作用构造不变；
- 不对包含常数与位置积分方向的完整A声称严格收缩。

这不是稳定性证明。它只是一种可回退、可量化容量的20步拟合限制。

### 4.4 多步损失

对全部`h=1...20`做teacher-free递推：

```text
L20 = sum_h w_h * (L_state,h + L_force,h + L_open,h) / 3
w_h = 2h / (20*21)

L = L20
  + lambda_anchor * (||ΔA||F^2 + ||ΔB||F^2 + ||ΔCF||F^2)
  + lambda_smooth * L_force_rate
```

- 三个误差组都按train尺度归一化，避免64维状态或18维受力因维数大而支配损失；
- `L_open`同时含前后向拉伸载荷`Q_FR`和左右向拉伸载荷`Q_LR`；
- `L_force_rate`是预测四点力后向差分与真实因果后向差分之间的归一化MSE，不是单纯把预测变化压到0；
- `lambda_anchor=1e-3`，且三项修正先各自除以对应基线矩阵F范数再平方；`lambda_smooth=1e-2`；M2使用同一损失和零修正初值，但不施加低秩与范数投影；
- 作用—反作用若由结构保证，只报告为恒等检查，不算精度收益；
- validation选择指标固定为10–20步`state/connector/opening`三项NRMSE等权平均。

### 4.5 训练预算

- M3候选网格：3个秩 × 3个修正上限，共9组；不追加结果驱动网格；
- 首个模型seed用于9组validation搜索；选定唯一配置后训练seed `74201–74205`；
- M2只使用与M3相同的优化轮数和五seed，不允许更大预算；
- 优化器固定为AdamW（`lr=5e-4, weight_decay=0`），batch=`256`，最大`80` epoch，梯度范数裁剪=`1.0`；训练/validation窗口均为20步、stride=`20`；
- early stopping patience=`10`，validation综合指标最小改善量=`1e-5`；学习率、batch、epoch、patience和损失权重不进入事后搜索；
- early stopping只看validation综合指标，恢复最佳epoch；
- 保存每个epoch的1步、10步、20步分组误差，防止只优化平均值；
- 训练时间、参数量、H=20推理P50/P95/P99同时记录。

## 5. fixed S4传感压力与S5降级实验

### 5.1 为什么必须单独做

K3压力结果来自trainable S4，不能直接证明K2 fixed S4也会以相同比例退化。fixed S4 clean预测更好，但读取实时四点力、货物拉伸载荷和力变化率；这些量在通信/传感延迟下可能产生比S5更大的递推偏差。

### 5.2 压力集合

每条压力trace先在validation冻结，再原样用于confirm：

| 编号 | 压力 |
|---|---|
| `P0` | clean |
| `P1` | 四点独立2%高斯噪声 |
| `P2` | 四点固定2% bias |
| `P3` | AoI 1、2、4个采样周期 |
| `P4` | 独立随机丢包10%、30% |
| `P5` | Gilbert–Elliott突发丢包；参数在生成前冻结 |
| `P6` | 单点连续缺失0.5 s、1 s、2 s |
| `P7` | 四点DoS 0.5 s、1 s、2 s；2 s过门前不做5 s |

### 5.3 观测处理对照

| 编号 | 处理 |
|---|---|
| `W0-zero` | 缺失力直接置零；仅作错误基线 |
| `W1-zoh` | 保持上一有效值 |
| `W2-impute` | 使用不读取力输入的M1 S5在`k-1`时刻给出的单步预测`F_hat(k|k-1)`填补；K4.1不得使用尚未训练的M3，也不读取未来真值 |
| `W3-S5` | 全程使用不读取力输入的S5-operational |
| `W4-supervisor` | 力新鲜时使用fixed S4，AoI/丢包越门时切到S5，并设恢复滞环 |

`W4`的可靠度只由当前可用信息计算：

```text
r(k) = min_i mask_i(k) * exp(-AoI_i(k)/tau)
```

`tau`、切出阈值和恢复阈值只在validation的固定小网格选择。S4和S5分别维护自身预测状态，切换时在共同30维物理输出上重新初始化；禁止把缺失置零后的S4状态传给S5。

压力实验采用滚动起点、teacher-free 20步评价。每个时刻`k`只让四点连接力消息经历P1–P7，30维物理状态和S3形变/相对速度保持当前可用，以隔离“显式力输入通道”的作用；观测管理器先按W0–W2处理四点`Fx/Fy`，再由处理后的四点力因果重算`Q_FR/Q_LR`和后向差分力变化率，不能分别向这10个派生量注入互相矛盾的数据。每个滚动起点用时刻`k`可用观测初始化模型，此后1–20步不再读取真实中间状态或未来网络消息。W4在每个滚动起点只按当时的`mask/AoI`选模型，不能按该窗口事后误差选择。

### 5.4 状态合同门G41

fixed S4只有同时满足以下条件才可作为clean增强模型：

1. 只在validation上计算：clean 10–20步综合指标相对S5改善至少10%；旧test/external数值只作开发审计，不能参与选择；
2. 在AoI=1、10%随机丢包和单点0.5 s缺失下，先在validation冻结唯一因果处理策略及W4阈值；该冻结候选相对S5的任一主要指标不得恶化超过5%，禁止逐轨迹或逐压力事后选择“最佳处理”；
3. 在`P0 + 上述三种轻压力`的逐轨迹配对汇总上，连接力或货物拉伸载荷至少一项的相对差`(candidate-S5)/S5`之paired bootstrap 95% CI上端严格小于0；bootstrap seed固定为`74501/74502`；
4. W4切换次数、恢复次数和最短驻留均受记录；在上述三种轻压力中，任一相邻切换间隔不得小于5个控制周期，且总切换率不得超过`0.5 Hz`，不能通过逐包切换换取误差；若本轮违反该条，直接按G41失败回退S5，不得看完结果后重调同一W4网格；
5. 不使用未来力或真实中间状态填补。

若G41失败：主模型固定为S5-operational，S4只保留为clean传感上界，不进入控制器。若G41通过：控制器可使用W4，但S5仍是强制fallback。

### K4.2 20步锚定修正开发

2. 运行9组M3 validation搜索并冻结唯一配置；

5. 检查每个seed的修正范数、数值有限性、误差随时域增长和失败场景。

进入confirm的开发门G42：

- M3相对M1的validation 10–20步综合NRMSE改善至少8%；
- 五seed至少4个方向一致；
- state、connector、opening任一项不得恶化超过5%；

- M3相对M2的判定固定为二选一：validation五seed平均综合NRMSE至少低1%；或平均综合NRMSE不高于M2的101%，同时归一化修正量`R=sqrt((||ΔA||F/||A0||F)^2+(||ΔB||F/||B0||F)^2+(||ΔCF||F/||CF0||F)^2)`不超过M2的50%，且五seed综合NRMSE标准差不高于M2。否则不能声称“锚定”有独立价值。

若G42失败：停止，不生成confirm、不接入MPC；本轮已经触发该条，最终采用M1 fixed S5-operational并删除“20步明显改进”主张。

### K4.3 一次性独立确认【因G42失败未执行】

## 7. 闭环实验顺序【因G42失败未执行】

只有G43通过才执行。所有控制器使用同一四车—货物plant、共同ICR、连接器参数、参考轨迹、初始条件、控制权重、求解器预算和seed。

### 7.1 方法对照

| 编号 | 控制器 |
|---|---|
| `C0` | AKE-M基线 |
| `C1` | NR-KDCC + M1 fixed predictor + 同一受力约束/网络保护 |
| `C2` | NR-KDCC + M3 K4 predictor + 同一受力约束/网络保护 |
| `C3` | C2去掉四点受力/货物拉伸载荷预测约束；归因消融 |
| `C4` | C2去掉W4/S5通讯降级；网络归因消融 |

不得让C2独享不同控制权重、参考轨迹、轮胎/连接器参数或更长求解时间上限。

### 7.2 顺序一：先证明通讯干扰会造成问题

在100 m分阶段工况上先使用C1/C4：

- 前30 m匀加速，建议`a_x=0.5 m/s^2`；
- 30 m后匀速，持续5 s正阶跃转向，再持续5 s反向阶跃转向；
- 剩余路段减速；
- 先clean，再注入1–3周期delay+10% loss和2 s DoS；
- 只做seed 3401诊断，不用于最终统计。

若通讯干扰没有使预注册的跟踪、力或不可行率指标明显恶化，不得预设“需要通讯保护”；应停止网络保护贡献叙述。若复现C3中的内部力恶化，再进入W4保护对比。

### 7.3 顺序二：正常通讯下单移线

比较C0/C1/C2/C3，先回答：

- K4 predictor相对fixed predictor是否有独立闭环收益；
- 收益来自20步预测还是受力约束；
- 四车单车横摆和阵列横摆是否同步改善；
- 货物左右侧/前后侧受力是否降低，而不是仅阵列合力变小。

### 7.4 顺序三：正常通讯下回头弯

使用相同方法和seed，重点检查持续曲率下：

- 四车转向分配与共同ICR残差；
- 四点`Fx/Fy`方向、货物合力与合矩；
- 左右向/前后向货物拉伸载荷、各车横摆与系统横摆；
- 入口、稳态弯中、出口三个阶段的10–20步预测误差。

### 7.5 顺序四：通讯扰动与DoS

只在clean单移线和clean回头弯均过门后执行：

1. 固定delay+loss；
2. Gilbert–Elliott突发丢包；
3. 2 s DoS；
4. 2 s DoS过门后才做5 s DoS；
5. 最后才做执行器故障+网络扰动联合工况。

每一步先比较C2与C4确认网络保护归因，再与C0/C1比较总体性能。某一步内部力门失败，停止更强攻击。

### 7.6 顺序五：H=8/12/16/20

- 离线模型仍统一评价1–20步；
- MPC时域分别运行8/12/16/20；
- 报告跟踪、受力、不可行率、P50/P95/P99求解时间和超时率；
- 若H=20没有覆盖计算代价，控制器保留H=12，但仍可报告模型的20步预测能力。

## 8. 动力学与受力验收量

每个工况必须同步记录：

1. 四车和货物的`vx/vy/yaw_rate/yaw`；
2. 阵列系统横摆与四辆单车横摆差；
3. 四连接点`Fx/Fy`、合力方向角`atan2(Fy,Fx)`和力变化率；
4. 货物平面合力`sum(F_i)`与绕质心合矩`sum(r_i × F_i)`；
5. 左右向拉伸载荷`Q_LR`、前后向拉伸载荷`Q_FR`和现有经过验收的受拉风险代理；
6. 每个点相对货物质心的向外投影，标记拉伸、压缩或近零；
7. 轨迹误差、横摆误差、控制输入、饱和、fallback和约束余量；
8. 预测器耗时、MPC求解时间、不可行率和任务完成率。

受力方向图必须画货物轮廓、四个连接点、同一比例尺的`Fx/Fy`箭头、合力和合矩方向。受拉风险判断使用plant中已冻结的`Q_FR/Q_LR`货物拉伸载荷；在没有材料截面、强度、疲劳和三维垂向载荷数据前，只能写“仿真货物拉伸载荷/受拉风险代理”，不能写“货物不会撕裂”。

## 9. 闭环验收门G44

### 9.1 clean价值

- C2相对C1至少一个预注册主要跟踪指标改善10%；
- 四点连接力峰值和左右向/前后向货物拉伸载荷P99均不得恶化超过5%；
- 任务完成率不得下降，MPC不可行率不得增加超过1个百分点；

### 9.2 通讯保护价值

- 干扰下C2相对C4的跟踪或内部力至少一项改善10%；
- 其余主要指标不得恶化超过5%；
- 2 s DoS期间不得出现数值发散、连续控制饱和或无记录的模型切换；

### 9.3 实时性

- H=20总求解P99必须小于控制周期；
