# GPU 作为后续实验执行平台的决定与登记（2026-09-16）

用户决定：**"当作一样的，把后面的实验也用 GPU 加速"**。本文是该决定的权威记录，规定它授权的范围、它的实测依据、由此产生的执行规则，以及它**不**授权的事项。任务书`experiment.md`第48节引用本文。

---

## 1. 决定

自2026-09-16起，**REV\paper_v4下的后续动力学实验一律在 RTX 5080 路径执行**，包括R5（合法信息接口）、C3（执行器九短片段）以及其后的K/M/N/B各阶段。CPU parallel8路径保留为**历史基准与交叉核验手段**，不再作为新实验的默认执行平台。

平台更换**不改变**任何科学定义：控制律、植物、N=20、控制步长20ms、预测步长2ms、`lambda_internal=2`、`frozen_dynamics_jacobian=False`、差分步长1.0、路线与参考速度、15000N极限力/轮胎1.0/支承≥0三道硬门，以及第9节的统计门与判据，全部逐项不变。

---

## 2. 实测依据（"一样"指的是哪一层）

### 2.1 物理结果同一 —— 已测

| 对照 | 实测 | 来源 |
|---|---|---|
| GPU(P1-2ms) vs CPU(P1-2ms前缀)，2200 tick / 88 m | 位置最大偏差 **2.398451e-05 m（24 µm）** | `analysis/20260915_R4_P1_2MS_GPU_COMPARE_03` |
| 同上，航向 | 1.945662e-05 rad | 同上 |
| 点力峰值 | GPU `263.3731042380` vs CPU `263.3731069866` N（相对1.0e-08） | 同上 |
| 最大构形误差 | GPU `12.562508469 mm` vs CPU冻结记录 `12.562509 mm`（**6位有效数字一致**） | 同上 |
| G3 力承载/转向限幅/晚段 三窗口（30 tick） | 8.856e-10 / 2.573e-10 / 5.289e-06 m | `analysis/20260915_G3_RESTART_EQUIVALENCE_02` |
| 固定样本 G1 六类物理量 | 最差归一化误差 8.05e-07（门=1，余量约6个数量级） | `results/20260915_RTX5080_G0_G2_05` |

**判定**：GPU 与 CPU 在已登记容差内给出**同一物理结果**。这是"当作一样的"的实测基础。

### 2.2 并非逐位同一 —— 已测，必须写清

24 µm ≠ 0。跨后端差异随闭环时间增长：G3力承载窗口30 tick为8.9e-10 m，而2200 tick累积到2.4e-05 m；晚段free-play窗口30 tick即达5.3e-06 m。

**因此：任何逐位级门（例如 R5-N0 的 1e-12 白名单门）不得跨后端使用。**

### 2.3 GPU 自身逐位可重复 —— 本次新测

`analysis/20260916_GPU_DETERMINISM_PROBE_01`：同一配置（P1、2ms、单CUDA worker、同冻结初值）各跑5 tick两遍。

| 项 | 结果 |
|---|---|
| 85列中逐位相同 | **84列** |
| 唯一不同的列 | `solver_wall_s`（墙钟） |
| 物理/控制白名单最大差 | **精确0.0** |
| 状态(30维) | **逐位相同** |
| solver首控制 | **逐位相同** |

**判定**：GPU 运行在**同后端内**是逐位可重复的——因此"无操作（no-op）门"在 GPU 上仍可保持1e-12的严格度，只要对拍对象也是 GPU 运行。

> 附带发现：该探针**首版结论是错的**——它比较了全部85列（含墙钟），报出`NOT_BITWISE_REPEATABLE`与一个**0.42的"差异"**，而那是纯墙钟。这与任务书第3节给`r5_batch._noiseless_difference`登记的缺陷**同类**，构成"物理/控制白名单比较"必需性的**现场证据**：全列比较会把墙钟当成0.42的物理违约。

## 3. 由此产生的执行规则（五条）

| 编号 | 规则 | 理由 |
|---|---|---|
| **P1** | 后续动力学实验一律在 GPU 路径执行；每次运行冻结协议、记录`implementation_id`与后端 | 本决定 |
| **P2** | **不变量门一律同后端对拍**（GPU↔GPU）；1e-12等严格门保持不变，不放宽 | §2.3：同后端逐位可重复 |
| **P3** | **跨后端**对照（GPU新跑 vs CPU时代旧run）按各自已登记容差报告，**不得写成逐位一致**；GPU↔CPU的等价性由G3三窗口与P1前缀2200 tick比较承担 | §2.2：24 µm ≠ 0 |
| **P4** | **墙钟(`solver_wall_s`)与时间(`time_s`)列永远排除在物理/控制比较之外**；时间按已登记的时间合同独立核对 | §2.3的现场证据；第22.3节"浮点实现差异不能自动用容差接受" |
| **P5** | 图与清单必须标注**执行后端**；不得因换后端而改图题、单位、门或裁决口径 | §25.3交付合同 |

## 4. "当作一样的"**不**授权的四件事

这四条必须与决定同时引用，防止后续被读成"GPU与CPU数据可以互相替代使用"：

1. **不授权把 GPU 新跑与 CPU 旧数据拼成同一条轨迹或同一批样本。** G3已实测证明中断的P1前缀不可续接（晚段free-play窗口重建检查点在1e-6 m门上失败），任务书亦禁止未证明等价的拼接。
2. **不授权跨后端使用逐位门。** 1e-12、32ε等逐位级判据只能用于同后端对拍。
3. **不授权以 GPU 加速宣称实时性。** 实测：P1-2ms均值4.226 s/最大5.281 s；P1-1ms最大4.722 s（2379/2379在5 s内）；**P2-0.5ms最大5.094 s、2348/2379在5 s内（31步超预算）**。全部为**离线**墙钟，不构成实时结论。
4. **不授权以 GPU 通过宣称方法优势。** R4是集中全状态诊断上界的数值/物理覆盖；P0/P0N/K0/K0N/K1/K1N六方法**均未运行**，Koopman、通信鲁棒、分布式与材料安全结论均未建立。

### R5 基准的书面取代

任务书第5节点名"新候选P0、2ms已重审的全状态基准（UNFROZEN_FULL01/2ms及U1重审）"。该CPU基准（`results/20260911_R3_UNFROZEN_FULL01/2ms`，`candidate_id=EXP-R3-unfrozen-v1`、`frozen_dynamics_jacobian=False`、`finite_difference_scale=1.0`、2379/2379、全长、墙钟77966 s）**继续作为跨后端等价性的对照**。

但 R5-N0 的"无操作"判据改为对**新增的GPU P0名义2ms基准**执行，理由是**隔离变量**：R5 要测的是"合法信息接口是否改变了控制输入"，若对拍对象跨后端，测到的将是已在G3单独资格化的后端差异，两个变化混在一起无法归因。**这是把变量分离，不是放宽门**：门仍是1e-12白名单逐位级，且同后端逐位可重复性已由 §2.3 实测支持。

登记要求：新基准须**单独冻结协议与输出目录**、独立`single_run_audit`、逐条图与清单，并在其协议中写明与CPU基准的关系及上述理由；CPU基准与U1重审记录**原样保留**，不被覆盖或追认。

## 7. 一句话总结

**GPU 与 CPU 给出同一物理结果（2200 tick 差 24 µm），GPU 与自身逐位同一（84/85列，唯一例外是墙钟）。因此后续实验在 GPU 上跑、严格门改为同后端对拍而一个都不放宽；但 GPU 数据不得与 CPU 旧数据拼批、不得跨后端用逐位门、不得据此宣称实时性或方法优势。**
