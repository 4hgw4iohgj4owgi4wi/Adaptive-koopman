## 4. 数学定义与候选方法

### 4.1 当前执行器

令`delta_req`为分配器请求轮角，`delta_act`为实际轮角，采样间隔为`Delta t`：

\[
a=\exp(-\Delta t/\tau_\delta),\qquad
\delta_{i,k+1}^{free}
=a\delta_{i,k}^{act}+(1-a)\delta_{i,k}^{req}.
\]

当前实现再依次施加：

\[
\left|\delta_{i,k+1}-\delta_{i,k}^{act}\right|
\leq \dot\delta_{max}\Delta t,
\qquad
|\delta_{i,k+1}|\leq\delta_{max}.
\]

冻结参数为`tau_delta=0.12 s`、`dot_delta_max=1.2 rad/s`、`delta_max=15 deg`。这些只是仿真合同，不是实车参数。

### 4.2 请求层归因

保持同一状态`x_k`和虚拟前后转角，构造：

- G0：仅`kinematic_targets()`生成的共同ICR几何前馈；
- G1：G0加当前四车独立航向反馈，但不裁剪；
- G2：G1再逐车裁剪，为当前真实请求层。

分别计算统一的轮角ICR残差`e_req(G0/G1/G2)`。贡献定义为：

\[
\Delta_{feedback}=M(G1)-M(G0),\qquad
\Delta_{clip}=M(G2)-M(G1),
\]

其中`M`同时包括峰值、P95、RMS、`>0.5 m/s`占比和恢复时间。差值允许为负，禁止只报告绝对值较大的有利项。

### 4.3 执行器A0–A3归因

在相同G2请求、相同初态和外部命令下比较：

| 模式 | 一阶滞后 | 速率限制 | 角度限制 | 用途 |
|---|---:|---:|---:|---|
| A0 | 否 | 否 | 否 | `actual=request`理想下界 |
| A1 | 是 | 否 | 否 | 单独估计带宽影响 |
| A2 | 是 | 是 | 否 | 增量估计速率限制影响 |
| A3 | 是 | 是 | 是 | 当前完整基线 |

对任一指标`M`：

\[
\Delta_{lag}=M(A1)-M(A0),\quad
\Delta_{rate}=M(A2)-M(A1),\quad
\Delta_{angle}=M(A3)-M(A2).
\]

该分解只在冻结实验域内解释增量，不声称对所有参数全局可加。

### 4.4 候选C1：统一曲率可行化

令`kappa_des`为虚拟四轮转向命令对应的阵列曲率，`g_i(kappa,x_k)`为现有`kinematic_targets()`在当前状态下给出的第`i`辆车几何轮角。不要另写未经验证的简化阿克曼公式。

为使下一步几何轮角可由当前执行器达到，先根据一阶模型反算请求：

\[
\delta_{i,k}^{inv}(\kappa)
=\frac{g_i(\kappa,x_k)-a\delta_{i,k}^{act}}{1-a}.
\]

定义一步可行集合：

\[
\mathcal K_k=\left\{\kappa:\begin{array}{l}
|g_i(\kappa,x_k)|\leq\delta_{max},\\
|g_i(\kappa,x_k)-\delta_{i,k}^{act}|\leq\dot\delta_{max}\Delta t,\\
|\delta_{i,k}^{inv}(\kappa)|\leq\delta_{max},\quad i=1,\ldots,4
\end{array}\right\}.
\]

从同一个可行曲率生成四车轮角：

\[
\kappa_k^\star=
\arg\min_{\kappa\in\mathcal K_k}
w_\kappa(\kappa-\kappa_k^{des,corr})^2
+w_s(\kappa-\kappa_{k-1}^\star)^2.
\]

四车航向误差不得继续直接分别加到四个轮角上。先形成阵列层修正，例如：

\[
\kappa_k^{des,corr}=\kappa_k^{des}
+k_\psi\bar e_{\psi,k}+k_r\bar e_{r,k},
\]

其中平均/惯量加权误差的定义必须固定并通过左右镜像测试。若阵列层修正不足以控制单车相对航向，可在第二层优化中加入软约束，但不得重新逐车无约束裁剪。

推荐实现是一维有界搜索或单调区间投影，不优先引入高成本通用QP。任何空可行集必须落盘，实验中禁止静默回退。

### 4.5 候选C2：统一曲率加执行器预测补偿

C2使用`delta_inv(kappa_star)`作为请求，并保留物理执行器的真实滞后、速率和角度限制。要求：

- 逆模型只使用当前`delta_act`、当前状态和已知当前命令；
- 不读取下一时刻真实状态或未来实际轮角；
- 有请求幅值、请求变化率和抗饱和；
- 若目标一步不可达，应由曲率参考管理器降低`kappa_star`，不能产生大命令后交给逐车clip。

### 4.6 Koopman因果状态

无论最终采用A3、C1还是C2，后续数据至少保留：

\[
s_k^\delta=
[\delta_{1:4,k}^{act},\dot\delta_{1:4,k}^{act},
\delta_{1:4,k}^{req}-\delta_{1:4,k}^{act},
m_{1:4,k}^{rate},m_{1:4,k}^{angle}].
\]

当前时刻可计算的门控上下文可包括：

\[
\rho_k^\delta=
[|\Delta\delta_k^{req}|,
\|\delta_k^{req}-\delta_k^{act}\|_2,
e_{ICR,k}^{act},
\max m_k^{rate},
\max m_k^{angle}].
\]

多步滚动时：未来虚拟/请求命令来自已知控制序列；未来实际轮角、速率和饱和状态必须由执行器侧车递推，禁止读取未来真值。

## 7. 顺序任务树与硬门

### I0 — 新版本冻结

**前置：** 用户明确授权I0–I1；5080无未知训练进程。

**FAIL：** 身份漂移、父数据缺失或未知进程无法解释时立即停止。

### I1 — G0–G2与A0–A3根因归因

**动作：** 只增加模式开关和审计，不实现C1/C2。  
**硬门：**

- A3必须逐点复现父F3公共字段，最大差`<=1e-12`或给出首个确定浮点来源；

- 所有模式有限、时间网格/100 m停止合同/作用反作用/内部力/支承守恒通过；

**输出：** `request_attribution.csv`、`actuator_attribution.csv`、每条轨迹原始NPZ、manifest、三层图、受力和横摆图。

### I2 — 候选实现

**前置：** I1报告证明H1/H2至少有一个成立，并获得单独授权。

**单元硬门：**

### I3 — 6成员候选smoke

**前置：** I2单元测试全部PASS。  
**资源门：** 先记录单条和回放墙钟；外推I4必须低于3 h或另行冻结线程/缓存优化协议。  
**候选筛选：** 先检查全部硬门，再按以下顺序：

1. 任何候选出现负支承、轮胎`>0.90`、连接器极限、重放或守恒失败，淘汰；
2. 候选在6/6成员中实际ICR峰值不得恶化；
3. 在剩余候选中选择切换窗复合指标最小者；

### I4 — 完整D2配对验收

**前置：** I3 PASS并获得单独授权。  
**实际ICR主要研究门：** 相对A3，候选必须同时满足：

- `e_act>0.5 m/s`时间占比中位数下降`>=50%`；
- 反向切换恢复时间中位数下降`>=50%`；
- 至少10/12条在三项中方向一致，且最坏轨迹不得恶化`>10%`。

这些是预注册相对研究门，不是实车安全限值。

**非退化门：** 相对A3成对比较：

- 横向轨迹RMS、航向RMS和货物横摆RMS任一中位数不得恶化`>5%`；

- 四点支承非负，载荷/力矩守恒、作用反作用、内部力、镜像、回放和数值有限性全部通过；
- 报告12条轨迹级成对bootstrap 95%区间，但小样本下不以单一p值替代上述物理门。

**决策：**

- 全部主要门和非退化门PASS：候选可成为新统一植物，进入I5；
- ICR改善PASS但跟踪或受力退化：状态记为`TRADEOFF_REVIEW`，不得采用；
- ICR主要门未通过：保留A3，不继续优化到“过门”；进入I5的“保留当前植物”分支；
- 任一物理硬门失败：I5及F4 NOT_RUN，生成`solutions.md`。

## 10. 跑不动、失败和解决方向

| 问题 | 最小诊断 | 允许处理 | 禁止行为 |
|---|---|---|---|
| A3不能复现父F3 | 对比首个不同字段、调用路径、dt和配置SHA | 只修隔离导入/模式开关，重跑I0 | 在不一致基线上继续归因 |
| G0不接近零 | 合成直线/稳态弯手算几何、坐标和端点 | 修指标或几何实现 | 用C1掩盖指标错误 |
| 一步可行集合为空 | 保存四车当前角、目标角、速率余量和瓶颈车辆 | 降低统一曲率或保持上一可行曲率并显式标记 | 四车各自clip后假装共ICR |
| C2请求尖峰 | 检查`1-a`、dt、tau和逆模型条件数 | 增加统一曲率参考管理、请求正则和抗饱和 | 放宽执行器速率/角度 |
| ICR下降但路径滞后增加 | 比较相同外部命令下轨迹、航向和完成距离 | 调整预注册范围内权重；若超范围则新协议 | 只展示ICR图并采用候选 |
| 受力峰值下降但冲量上升 | 时间对齐后计算切换后1 s绝对冲量 | 重新检查参考管理器与连接器相位 | 只报告更小峰值 |
| 镜像失败 | 检查车辆索引、曲率符号和阵列误差加权 | 修映射并重跑该阶段全部成员 | 只删除失败方向 |
| 数值步长解析不了转向边界 | dt减半/再减半比较角度、力峰值、冲量和终态 | 新协议下增加事件/子步 | 仅凭更平滑曲线通过 |
| 运行超过预算 | 先做固定6成员smoke，记录进程×MKL线程 | I0冻结单线程或缓存不变计算并证明数值一致 | 运行中改线程、删回放/seed |
| Koopman切换窗不改善 | 查轮角字段时序、未来泄漏和专家占用 | 保留负结果；回退共享简单骨干 | 增加未来真实轮角或删切换窗 |
