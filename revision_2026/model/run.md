## 2. 必须保留的模型结构

1. 四辆车分别积分 `[X,Y,psi,vx,vy,r]`；
2. 货物分别积分 `[X,Y,psi,vx,vy,r]`；
3. 四连接器按车辆/货物锚点相对位移和速度产生平面 `Fx/Fy`；
4. 车辆受 `−F_i`，货物受 `F_i`；
5. 两个分力进入单车纵向、横向和横摆动力学；
6. 连接反力及锚点力矩进入货物动力学；
7. 联合RK4每个stage重算连接力；
8. 虚拟4WS转角只确定共同ICR，每车获得独立车体方向、速度和自行车转角；
9. 原等效4WS模型只作为上层命令和对照，不重新替代全耦合plant。

## 5. 单项实验设计

### E0：静止和匀速直行

- `a=0`、虚拟前后角均为0；
- 检查四点力、横摆率和ICR退化；
- 目的：确认模型不会凭空产生内力或横摆。

### E1：单点四方向加载

每次只让一个锚点产生 `+x/−x/+y/−y` 位移，再分别给正负相对速度。四个连接点共32个基础算例。

输出：货物力、车辆反力、方向角、两个刚体的横摆力矩、储能和阻尼功率。

### E2：单车响应

关闭轮胎控制输入，向单车施加已知 `Fx/Fy`，用一步解析导数对照数值积分：

```text
Δvx_dot=Fx/m
Δvy_dot=Fy/m
Δr_dot=(a_x Fy−a_y Fx)/Iz
```

每车分别测试，禁止只验证FL后推断其余三车。

### E3：货物与复合系统

给四点构造：同向纵向、同向横向、纯横摆、前后对向、左右对向和对角六种模式。

检查：货物合力/合矩、复合系统内部力抵消、张开代理符号及零合力但非零内部载荷情形。

### E4：前30m加速

- 初速 `2m/s`；
- `a=0.5m/s²`；
- 理想目标速度约 `sqrt(2²+2×0.5×30)=5.83m/s`；
- 转角为0。

重点：四点Fx方向、单车速度、货物加速度、系统总外力、连接器能量和Fz载荷转移。

### E5：正阶跃

- 30m后 `a_cmd=0`；
- 虚拟前/后角 `+4°/−2°` 持续5s；
- 由共同ICR分配器生成四车独立转角和速度修正。

重点：内外侧Fy、四车横摆、系统横摆、货物左右侧合力、四点方向角和速度损失。

### E6：反阶跃

- 紧接E5，虚拟前/后角 `−4°/+2°` 持续5s；
- 所有左右镜像指标与E5对照。

### E7：减速

- 转向回零；
- 按剩余距离计算固定减速度；
- 目标为100m内速度降至 `≤0.5m/s`，不得反向行驶。

重点：四点纵向反力方向是否反转、货物减速度重构和前后Fz转移。

### E8：功能消融

固定同一初始状态、同一虚拟指令，分别运行：

1. 完整分配；
2. 仅ICR前馈；
3. ICR前馈+方向反馈；
4. ICR前馈+零和速度修正；
5. 错误前后角直接复制；
6. connector-off。

用于区分共同ICR、方向反馈、速度修正和连接器本身的独立贡献。

## 7. 验收门

### G0/G1：转向

- 直行四车目标方向和转角为0；
- `max |v_normal|≤1e-8m/s`；
- 左右弯ICR、速度和方向满足镜像；
- 同一稳态弯四车前馈转角产生同号横摆；
- 方向反馈和速度修正的贡献由消融单独报告。

### G2/G3：连接器与单车

- 间隙内力为0；
- 作用反作用逐分量误差 `≤1e-9N`；
- 阻尼功率非负；
- 解析和数值 `Δvx/Δvy/Δr` 相对误差 `≤1%`；
- 四车、四方向全部通过。

### G4：货物与阵列

- 四点力重构货物加速度相对误差 `≤1%`；
- 四点力矩重构货物横摆角加速度相对误差 `≤1%`；
- 内部力闭合残差 `≤1e-9N`；
- 必须复现“总合力为0但内部张开载荷非0”的算例。

### G5/G6：分阶段和100m

- 完成距离 `100±0.1m`；
- 最终速度 `≤0.5m/s`且不反向；
- 正反阶跃平均Fy和系统横摆符号反转；
- 连接峰值低于参考额定12kN，但只能称参考参数下通过；
- `dt/2` 的峰值力、横摆峰值、完成时间差 `≤5%`；
- 无NaN/Inf，无状态裁剪掩盖失败。

### G7：适用域

不能只报告当前一组参数。必须给出连接参数、锚点、速度、载荷、附着和转向幅值的通过/失败边界。

2. 任一点作用反作用不闭合；
3. Fx/Fy没有按解析符号影响对应单车；
4. 货物加速度/横摆不能由四点力重构；

## 12. 控制与网络实验总顺序

物理模型完成 `T0–T7` 后，控制实验严格按以下顺序执行，不得把正常工况、复杂道路和攻击工况混在同一批次：

```text
C0 当前100m工况加入通讯干扰
   ↓ 用受力、跟踪误差和约束违反检验通讯保护必要性
N0/N1 建立网络模拟器并实现通讯保护
   ↓
C1 正常通讯下单移线：AKE-M vs NR-KDCC
   ↓
C2 正常通讯下回头弯：AKE-M vs NR-KDCC
   ↓
C3 通讯扰动和DoS下：AKE-M vs NR-KDCC及保护消融
   ↓
C4 统计、适用域和论文证据审查
```

第一阶段的结论不能预设为“需要通讯保护”。只有通讯干扰使误差、连接力、内部张开载荷或约束违反出现可重复退化，才得出保护必要性；若没有退化，应报告当前工况不敏感，而不是人为增大干扰直到得到期望结论。

## 13. C0：先用当前工况暴露通讯问题

### 13.1 固定物理和控制基础

使用已经通过的共同ICR四车—连接器—货物模型和同一100m输入：

- 初速 `2m/s`；
- 前30m `a=0.5m/s²`；
- 正向虚拟4WS阶跃5s；
- 反向阶跃5s；
- 剩余路段减速。

本阶段控制器使用**不带通讯保护的基础协调控制**。物理参数、转向分配、初始状态和控制器参数全部冻结，只改变网络轨迹。

### 13.2 通讯干扰由轻到重

按控制周期 `Tc` 表示时延，避免先验绑定某一采样时间：

| 网络级别 | 时延 | 丢包 | 抖动/乱序 | 突发中断 |
|---|---|---|---|---|
| N-clean | 0 | 0 | 无 | 无 |
| N-light | `0–1Tc` | 2% | 轻微 | 无 |
| N-medium | `1–3Tc` | 10% | 有 | 0.2–0.5s |
| N-heavy | `3–6Tc` | 20% | 明显 | 0.5–1.0s |

丢包不能只用独立Bernoulli模型；同时使用Gilbert–Elliott突发模型。所有方法必须重放完全相同的网络trace。

### 13.3 先看受力，再看误差

受力指标优先：

- 四连接点 `Fx/Fy` peak、RMS、P95、P99；
- 额定力利用率和超限持续时间；
- 左右侧、前后侧货物合力；
- `Q_front_rear/Q_left_right/Q_diag`；
- 力方向突变、力变化率和恢复冲击；
- 四车轮胎利用率与局部饱和。

误差指标随后报告：

- 货物质心横向/纵向RMSE和峰值；
- 四辆单车横向、航向和速度误差；
- 阵列相对位置/航向误差；
- 货物横摆和系统横摆误差；
- 100m完成率、完成时间和最终速度。

网络状态同时记录：delay、drop indicator、packet age、乱序、连续丢包长度和每条边的有效质量。

### 13.4 通讯保护必要性判据

当满足下列任一条件且在配对多种子中可重复时，才判定需要通讯保护：

1. 任一连接器超过已确认的工作阈值；
2. 连接力P95/P99、力变化率或张开代理相对clean显著增大；
3. 货物/车辆误差超过预设约束；
4. 阵列完整性、完成率或稳定性下降；
5. 网络恢复瞬间产生明显控制或连接力冲击。

结果写成“通讯退化→状态信息陈旧/不一致→控制分配偏差→单车运动差异→连接器内力→货物和阵列误差”的因果链，不能只展示packet loss与RMSE的相关性。

## 14. N0/N1：网络模型与通讯保护改进

### 14.1 网络模拟器

新增独立网络层，不把丢包逻辑散落在控制器中：

```text
network/
├─ channel.py       # delay、loss、jitter、reorder
├─ burst.py         # Gilbert–Elliott与DoS
├─ packet.py        # timestamp、sequence、source、payload
├─ quality.py       # 因果链路质量和AoI估计
├─ replay.py        # 固定trace跨方法重放
└─ test_network.py  # 可复现性和边界测试
```

网络随机数与传感器噪声、模型扰动、控制器随机数使用独立seed流。网络trace先生成并冻结，再供AKE-M、NR-KDCC和消融方法共同使用。

### 14.2 通讯保护链

NR-KDCC的通讯保护按以下顺序实现和消融：

1. **包有效性检查**：时间戳、序列号、乱序、重复包和过期包；
2. **Age of Information**：每条边记录信息年龄，而不是只有收到/没收到；
3. **延迟外推**：用本地模型把邻车旧状态外推到当前时刻；
4. **不确定性随AoI增长**：信息越旧，预测界越宽；
5. **链路质量加权**：降低不可靠邻车在consensus中的权重；
6. **约束收紧**：按通信/预测不确定性收紧连接位移、连接力和轮胎约束；
7. **DoS降级模式**：长时间失联时切换本地安全控制或冻结安全参考；
8. **恢复滞环与软恢复**：通讯恢复后逐步恢复邻车权重，避免控制和连接力跳变；
9. **可追溯fallback**：记录触发原因、持续时间和恢复条件。

链路质量估计必须只使用当前和历史可用数据，禁止读取未来丢包或真实隐藏网络状态形成oracle优势。

### 14.3 网络保护单元门

- 固定trace可逐位复现；
- 无扰动时保护层透明，不改变控制结果；
- 过期/乱序/重复包均被正确处理；
- 外推只使用过去信息；
- uncertainty bound随AoI不减；
- DoS触发与恢复条件无抖振；
- 软恢复阶段控制增量和连接力变化率有界。

## 15. C1：正常通讯下单移线对比

### 15.1 方法

必选：

- `AKE-M`：任务对齐的Adaptive Koopman Embedding基线；
- `NR-KDCC`：完整方法。

诊断消融：

- `NR-KDCC-noComm`：关闭communication awareness；
- `NR-KDCC-noForce`：关闭连接力目标/约束；
- 等效4WS传统MPC或network-aware consensus MPC作为非Koopman强基线（若实现可用）。

### 15.2 公平条件

统一：

- 新四车物理plant和共同ICR转向分配；
- 单移线路径、初始状态、速度和载荷；
- 状态、输入和连接约束；
- 预测时域、控制频率和求解容差；
- 调参预算、计算设备和终止条件；
- clean网络、相同seed和相同扰动trace。

AKE-M不得使用旧的等效plant结果与NR-KDCC的新物理plant结果比较。两种方法都必须在新plant上重新调参和运行。

### 15.3 单移线指标

主指标按以下顺序：

1. 货物质心和四车跟踪误差；
2. 四连接点力、方向和利用率；
3. 内部张开载荷；
4. 四车/货物/系统横摆；
5. 控制平滑性和轮胎利用率；
6. 求解时间、失败率和完成率。

clean条件下通讯保护应基本透明。若NR-KDCC仅靠更激进控制降低误差却显著提高连接力，必须作为Pareto权衡报告，不能写成全面更优。

## 16. C2：正常通讯下回头弯对比

在C1通过后进入回头弯。先使用平面单回头弯，再根据需要增加坡度；不要同时引入通讯攻击。

### 16.1 工况层次

1. 标称半径、标称速度和载荷；
2. 小半径；
3. 较高速度；
4. 重载；
5. 低附着；
6. 小半径+重载或低附着的组合边界。

### 16.2 对比

- AKE-M vs NR-KDCC；
- full ICR allocator vs allocator ablation；
- connector-on vs connector-off只作机理诊断；
- 必须使用相同路径、初始状态和物理参数。

### 16.3 回头弯重点

- 弯内/弯外四点Fy方向和峰值；
- 左右侧货物合力与载荷转移；
- 系统横摆、四车横摆一致性和ICR残差；
- 内侧车辆轮胎利用率；
- 入弯、弯中、出弯分段误差；
- 跟踪—受力—效率Pareto。

回头弯clean实验通过后，才能把它用于网络鲁棒性测试；否则无法区分曲率失稳和通讯失稳。

## 17. C3：通讯扰动和DoS对比

### 17.1 场景顺序

```text
R0 clean
R1 固定时延
R2 随机时延+jitter
R3 独立丢包
R4 Gilbert–Elliott突发丢包
R5 延迟+丢包+乱序
R6 短DoS
R7 长DoS
R8 周期DoS
R9 通讯扰动+执行器退化
```

先在单移线运行R0–R8，再选择有代表性的R0、R4、R6、R7用于回头弯。不要一开始就在回头弯叠加所有攻击。

### 17.2 DoS参数轴

- burst长度：`0.5/1/2/5s`；
- duty cycle：`10/30/50%`；
- 攻击对象：单边、单车全部入边、全图；
- 攻击时刻：入弯前、入弯、弯中、出弯；
- 恢复方式：瞬时恢复与软恢复对照。

DoS期间禁止把真实邻车状态直接传给预测器或绘图指标之外的控制器。

### 17.3 方法对比

- AKE-M；
- NR-KDCC full；
- NR-KDCC-noComm；
- NR-KDCC-noDelayPrediction；
- NR-KDCC-noTightening；
- NR-KDCC-noFallback；
- NR-KDCC-hardRecovery，用于证明软恢复的作用。

### 17.4 网络鲁棒性指标

除控制和受力指标外，增加：

- packet delivery ratio、平均/P95 AoI；
- 最大连续失联时间；
- 邻车状态外推误差；
- quality估计偏差；
- fallback次数和持续时间；
- DoS期间最大误差和最大连接力；
- 通讯恢复后的恢复时间、控制跳变和连接力冲击；
- 任务完成率和安全约束违反率。

## 18. C4：统计与证据规则

- 核心比较至少20个配对seed；
- 同一seed下所有方法重放同一网络、噪声和故障trace；
- 报告均值、SD、95% CI、中位数、P95/P99和worst case；
- 使用配对检验、效应量和多重比较校正；
- 同时报告不利结果；
- force peak更高时不得只展示RMSE优势；
- 以Pareto图展示跟踪、连接力、控制代价和计算时间。

证据层级：

- E1：单次/单seed现象；
- E2：多seed可重复趋势；
- E3：公平强基线下有统计支持；
- E4：跨单移线、回头弯和网络攻击仍成立。

论文核心结论至少达到E3。DoS韧性主张必须达到E4。
