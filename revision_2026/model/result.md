# ICR复测结果

## 结论

共同ICR转向分配通过100m验收。此前失败的主要因果变量是错误的四车转向映射，而不是连接动力学的数值发散。

## 同工况对照

| 指标 | 直接前后角复制 | 共同ICR分配 |
|---|---:|---:|
| 完成路程 | 52.1515m/失败 | 100.0005m/通过 |
| 连接力峰值 | 20.910kN | 2.220kN |
| 系统横摆峰值 | 0.7973rad/s | 0.1431rad/s |
| 正阶跃平均货物Fy | +1831N | +1496N |
| 反阶跃平均货物Fy | −538N | −1581N |
| ICR法向速度残差 | 未约束 | `1.06e-14m/s` |
| 步长收敛 | 通过 | 通过 |

连接峰值下降约89.4%，系统横摆峰值下降约82.1%。四点连接力没有超过参考额定12kN。

## 转向分配含义

虚拟前后角只用于确定阵列ICR。每辆车先取得自己的目标车体切向方向和ICR半径，再计算自身自行车转向。稳态同一左转中四辆车的自行车转向前馈产生同号横摆；后车相对货物的目标车体方向可以为负，不能把这个方向角直接当成后车转向角。

## 货物受力

- 正阶跃货物平均横向合力 `+1495.83N`；
- 反阶跃货物平均横向合力 `−1580.52N`；
- 前后、左右张开代理仍出现正值，说明存在瞬态对向受拉模式；
- 没有货物材料、截面和连接区强度，仍不能判定实际撕裂。

## 仍未闭合的证据

- 连接刚度、阻尼、间隙和额定力来自参考项目，未按目标实物标定；
- 车辆锚点偏置仍是假设；
- 当前分配含车体方向反馈和零和速度修正，需要分别做消融；
- 阶跃曲率不连续，适合作为动态冲击验收，不代表实际可行道路轨迹；
- 尚未接入原 `tf14_runtime.py` 和原控制器主线。
