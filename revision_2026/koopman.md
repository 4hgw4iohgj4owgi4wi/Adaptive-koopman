# Koopman修正与审稿意见闭环方案

> 项目：VT-2026-05393 重投稿修正  
> 日期：2026-08-19  
> 目标：先解决审稿人关于 bilinear Koopman、20步预测、IRSP及其闭环价值证据不足的问题，同时盘点已有修改究竟关闭了哪些审稿意见。

## 1. 先给结论

当前 Koopman 问题的实验结论已经收敛为**回退固定线性模型**。K2三完整专家、K3共享可训练lift和K4低秩多步修正均触发预注册停止门。K4中M3相对M1的validation综合NRMSE只改善`6.95%`，未达到8%门；同时状态误差恶化`21.70%`，虽连接力和货物拉伸载荷预测分别改善`10.05%/7.63%`，仍不具备整体部署资格。最终允许使用的Koopman predictor为`M1 fixed S5-operational`。

原 IRSP 还存在确定性数学问题：投影后的 `A+` 满足有限样本谱半径约束，但 `||A+||₂=1.0980>r_u=0.998`。当原公式令 `gamma=0` 时，`A_eff=A+`，仍不满足连续输入域范数界。因此，继续用原 IRSP 支撑连续域收缩、递归可行性或稳定性是不成立的。

最新证据决策为：

1. **状态合同**：fixed S4 clean综合误差相对S5改善`10.95%`，但S4/S5 supervisor违反最短驻留和`0.5 Hz`切换率门；G41失败，部署合同回退S5-operational。
2. **20步候选**：M2全量refit更差；M3锚定修正虽改善受力预测，但状态与综合门失败；G42失败，回退M1 fixed linear。
3. **证据隔离**：确认集生成/查看均为`false`；K4.3、MPC、闭环和更强网络攻击均未执行，不能把现有控制收益归因于K4。
4. **论文处理**：删除神经lift、三专家、bilinear/IRSP和“20步明显改进”主张。后续若继续控制实验，只能以M1 fixed S5作为预测器，并把受力约束/网络保护作为独立问题研究。

术语统一：历史代码字段`opening`保留不改，以兼容JSON和checkpoint；中文正文统一称为**货物拉伸载荷**，其中`Q_FR`为前后向拉伸载荷、`Q_LR`为左右向拉伸载荷。它是单位为N的差动力代理，不是张开距离或材料撕裂概率。

## 2. 审稿人真正质疑的不是“步数不够”

审稿意见集中在四个因果缺口：

1. **预测价值缺口**：bilinear、bilinear+IRSP和线性AKE之间没有稳定优势，甚至简单模型横向RMSE更低。
2. **20步证据缺口**：即使论文使用或声称20步预测，也没有证明第2–20步误差优于基线，更没有证明这种改善传递到了闭环控制。
3. **理论缺口**：有限输入样本的谱半径小于1，不能推出连续输入盒上的 induced-norm contraction，更不能自动推出递归可行性和闭环稳定性。
4. **归因缺口**：完整系统包含通信感知、PPC、FDI/FTC、role、fallback等模块；最终改善可能来自这些模块而非Koopman。

所以不能只把 `horizon=12` 改成20。这样只会提高计算量，不能回答“为什么更好、由谁带来、是否可证明”。

## 3. 候选新方法：MF-IK（Multi-step Force-aware Incremental Koopman）

这是K2以前提出的历史候选路线，不应在通过实验门之前写成既成创新。K2/K3已经否定当前三专家和共享可训练lift实现，因此本节只保留为问题定义与变量合同依据，不再按原MF-IK任务树直接执行；当前执行结构见`k4.md`。

### 3.1 状态合同

从新的四车—货物物理plant重新生成数据，预测状态至少包含：

- 四辆车各自的纵/横向速度、横摆角速度和姿态误差；
- 货物平动、横摆和参考轨迹误差；
- 四连接点的水平/竖直变形与变形速度；
- 四点 `Fx/Fy` 或由形变严格计算的力状态；
- 前后向/左右向货物拉伸载荷和连接力变化率；
- 实际施加到各车的转向/驱动输入，而不是阵列聚合后的虚拟输入。

通讯AoI、丢包标志和模式状态不混入纯物理 Koopman 状态；它们作为外生调度变量或不确定性索引，避免把网络随机过程错误解释为物理自治状态。

### 3.2 变量集合变化实验

变量集合必须先于MF-IK结构选择完成，否则无法区分“模型形式改善”和“给了模型更多物理信息”。所有集合从同一原始日志按确定性转换得到，使用相同轨迹划分、样本时刻、归一化、训练轮次和调参预算。

#### 3.2.1 状态变量集合

| 编号 | 预测器输入状态 | 作用与待验证问题 |
|---|---|---|
| `S0-legacy31` | 原论文实际31D lifted模型对应的旧状态 | 冻结的历史基线，检查原表II能否复现 |
| `S1-team` | 货物状态 + 阵列聚合位置/速度/横摆，不含四车独立状态和连接器 | 复现“把系统看成一辆等效4WS车辆”的信息损失 |
| `S2-four` | 四车独立运动状态 + 货物状态，不含连接器形变/速度 | 判断四车独立状态本身的收益 |
| `S3-deform` | `S2` + 四连接点水平/竖直相对位移及相对速度 | 候选最小Markov物理状态，检验连接器记忆是否必要 |
| `S4-force-in` | `S3` + 四点Fx/Fy、前后向/左右向货物拉伸载荷和力变化率作为输入状态 | 检查显式力反馈是否改善长时预测；同时检查共线和维数代价 |

| `S6-net-in` | `S5` + AoI、drop mask、quality和模式变量进入lift | 仅作诊断，验证网络变量混入物理状态是否真的必要 |
| `S7-net-exo` | 物理输入用`S5`，网络变量只作为外生不确定性/调度索引 | 推荐的网络处理方式，与`S6`公平对照 |

`S4`中的力由连接器形变/速度确定，可能与`S3`高度共线。若`S4`只降低训练误差却不改善独立轨迹和闭环受力，优先选择`S5`，避免重复变量制造虚假优势。

#### 3.2.2 控制输入集合

| 编号 | 控制输入 | 目的 |
|---|---|---|
| `U0-team` | 原阵列聚合转角/加速度 | 历史基线 |
| `U1-four` | 四车实际施加的转向和纵向驱动输入 | 推荐物理输入，保留各车差异 |
| `U2-commanded` | 四车命令值而非实际施加值 | 量化执行器动态和饱和造成的模型偏差 |
| `U3-four+alloc` | `U1` + ICR目标/分配模式作为外生变量 | 检查分配模式切换是否需要显式条件化 |

主模型必须使用`U1-four`。`U2-commanded`只能作为传感/执行器信息受限时的诊断，不能与使用实际输入的模型直接宣称公平优越。

#### 3.2.3 公平控制

1. 数据按**整条轨迹/场景/seed**划分，禁止同一轨迹相邻窗口跨train/test造成泄漏。
2. 每个变量集合自动记录原始维数、lift维数和参数量；主表固定lift容量，附表做参数量匹配敏感性。
3. 归一化统计只由训练集计算；test中的力、状态和网络信息不得参与尺度拟合。
4. 所有模型使用同一20步teacher-free rollout评价；不能给某一模型使用真实中间状态纠偏。
5. force派生量只使用当前及历史可用量；力变化率采用因果差分，不得使用中心差分读取未来。
6. 同时报告精度、参数量、训练时间、推理时间和MPC求解时间，防止单纯靠扩大状态获胜。

#### 3.2.4 分阶段而非全组合爆炸

第一阶段固定线性/同一lift结构，只比较：

`S1-team → S2-four → S3-deform → S4-force-in/S5-force-out`。

先回答四个因果问题：四车独立状态是否必要、连接器状态是否必要、力应作为输入还是监督输出、聚合输入是否丢失关键动力学。

第二阶段只用第一阶段胜出的状态合同，对比：

`lifted linear AKE → one-step bilinear → 20-step bilinear → MF-IK`。

第三阶段才比较`S6-net-in`与`S7-net-exo`。这样避免把状态增加、双线性结构、多步损失和网络条件化四种变化同时发生。

### 3.4 增量/误差动力学

不再对包含常数 observable 的完整 lifted state 强求严格收缩。定义参考轨迹附近的增量状态：

`delta z_k = psi(x_k)-psi(x_ref,k)`，

并拟合

`delta z_(k+1)=A_delta delta z_k + Σ u_(k,l) N_delta,l delta z_k + B_delta delta u_k + w_k`。

这样证书对象与需要稳定的跟踪误差一致，常数项和沿参考轨迹前进的中性方向不再造成结构性矛盾。

### 3.5 20步联合训练

训练目标不只使用一步拟合：

`L = L_1step + λ_H L_rollout(1:20) + λ_F L_force + λ_P L_physics + λ_S L_smooth`。

- `L_rollout`：1–20步加权预测误差，权重和归一化在训练前冻结；
- `L_force`：四点Fx/Fy、货物拉伸载荷和力变化率误差；
- `L_physics`：作用反作用、货物合力/合矩重构和运动学一致性残差；
- `L_smooth`：抑制长时域预测中的非物理高频振荡。

必须同时训练以下公平基线：

- raw-state linear；
- lifted linear AKE；
- 原始一步 bilinear；
- 20步 bilinear但无受力/物理损失；
- MF-IK完整模型。

### 3.6 与MPC的接口

- 离线预测评价固定到20步；
- MPC分别测试 `H=8/12/16/20`，不能默认20步一定最好；
- 所有方法使用相同控制权重、约束、求解器预算和四车耦合plant；
- 若20步导致实时超时，论文必须区分“模型可预测20步”和“控制器实时使用20步”，不得混写。

### 3.7 多专家平滑门控：G-MF-IK候选

> 最新状态（2026-08-19）：K2三完整线性专家已触发停止门；K3共享可训练lift也在G32失败，方案B按预注册规则未训练。本节保留为已检验假设和设计依据，不再作为直接执行路线；K4不恢复完整专家或E-T残差。

#### 3.7.1 问题定义

这里要处理的是**工况相关的活跃子空间**，不是状态维度真的改变：

- 直线匀速时，横向速度、横摆和横向连接力变化很小；
- 加速/制动时，纵向力和前后向货物拉伸载荷成为主要变量；
- 稳态转弯时，横向速度、横摆、四点`Fy`和左右向货物拉伸载荷变得重要；
- 直线—弯道、正反转向和加减速切换时，多组变量会同时快速参与；
- 间隙、刚度或阻尼变化时，连接形变、相对速度和损伤/退化参数的敏感度发生变化。

因此所有专家必须共享同一个完整状态合同、lift空间和输出解码器。禁止在直线专家中直接删除横摆、货物或连接器状态，因为“当前变化小”不等于“下一时刻不重要”。

#### 3.7.2 三个基础专家

第一版只设置三个物理动力学专家，控制复杂度：

| 专家 | 主要覆盖工况 | 应重点建模的变量组 |
|---|---|---|
| `E-L`纵向专家 | 直线匀速、加速、制动 | `vx/ax`、四点Fx、前后向货物拉伸载荷、纵向连接形变 |
| `E-C`转弯专家 | 持续左/右弯、单移线主体、回头弯 | `vy/r`、四点Fy、左右向货物拉伸载荷、货物与四车横摆 |
| `E-T`过渡专家 | 入弯/出弯、正反转向切换、加减速切换 | 变量变化率、力变化率、门控切换瞬态和多轴耦合 |

连接器疲劳、间隙扩大或单点退化暂不立即增加第四专家。先把这些参数放入external-test；只有三专家在退化域出现稳定且可重复的结构性残差，才增加`E-D`退化专家，避免专家数量膨胀后用容量掩盖模型问题。

#### 3.7.3 门控变量与因果边界

物理工况门控输入定义为当前及历史可用量：

`rho_phys=[vx, kappa_ref, ax_applied, delta_applied, Q_FR, Q_LR, dot(kappa), dot(delta), dot(Q_FR), dot(Q_LR)]`。

- `kappa_ref`可使用控制器已知的参考曲率预览；
- `ax_applied/delta_applied`使用实际已施加输入，命令输入仅作受限信息诊断；
- `Q_FR/Q_LR`使用当前或历史因果计算值，不得读未来真实力；
- 变化率用后向差分或因果滤波，禁止中心差分读取未来；
- 原始量和变化率必须经训练集尺度归一化。

网络可靠性单独定义为

`rho_net=[availability_mask, AoI, sequence_valid, quality, fallback_mode]`。

`rho_net`用于观测估计、门控置信度、约束收紧和fallback，不默认进入物理lift。物理值缺失时输入`[x_hat, mask, AoI]`，不能把缺失值直接置零，否则模型会把“未收到”误解为“物理量为0”。这与`S7-net-exo`一致；`S6-net-in`只保留为诊断对照。

#### 3.7.4 平滑混合结构

先从线性专家开始：

`f_m(z_k,u_k)=A_m z_k+B_m u_k`，

`alpha_k=softmax(h_phi(rho_phys,k)/tau)`，

`z_(k+1)=Σ_(m=1)^3 alpha_(k,m) f_m(z_k,u_k)`，

满足`alpha_(k,m)≥0`且`Σ_m alpha_(k,m)=1`。

只有门控线性专家相对最佳固定线性模型通过独立test后，才允许把专家扩展为bilinear/MF-IK：

`f_m=A_m z+B_m u+Σ_j u_j N_(m,j)z`。

当前bilinear的20步误差明显更差，因此不能直接从三个bilinear专家起步。

为防止变量门控把完整状态信息截断，推荐采用“共享基模型 + 门控专家残差”：

`z_(k+1)=A_0z_k+B_0u_k+Σ_m alpha_(k,m) Delta f_m(D(g_m)z_k,u_k)`，

其中`g_m∈[0,1]^G`只调节纵向、横向/横摆、连接器、货物等**变量组对专家残差的作用**，共享基模型始终看到完整状态。这样比直接使用`g⊙x`删除状态更安全，也更容易做消融。

#### 3.7.5 门控训练与防塌缩

1. 用物理可解释阈值生成弱标签预热门控：低曲率/低变化率、持续曲率、输入或曲率快速变化；弱标签不作为最终真值。
2. 先分别训练三个专家，再冻结专家短暂训练门控，最后小学习率联合微调。
3. 加入门控平滑项`||alpha_k-alpha_(k-1)||²`和最大变化率限制，抑制工况边界抖振。
4. 使用场景均衡batch和全局负载均衡项防止单一专家吞并全部样本。
5. 同时限制门控长期完全均匀；报告门控熵、专家占用率和有效专家数，防止“看似三专家、实际一个平均模型”。
6. 过渡窗口在训练集中单独采样，避免`E-T`因时间占比小而学不到。
7. hard switch只作负对照，正式模型使用平滑权重；不得用真实场景标签在test时直接选择专家。

#### 3.7.6 MPC预测域内的门控

门控不能在MPC的20步内固定为当前值。对第`j`步：

- 使用已知参考曲率/计划输入和模型预测状态递推`rho_(k+j|k)`；
- 计算对应`alpha_(k+j|k)`并传播混合动力学；
- 若AoI或mask恶化，增加残差界和约束收紧，而不是切换成虚假的“网络物理专家”；
- 比较`frozen gate`与`recursive gate`，证明性能不是来自使用未来真实工况标签。

递归门控会增加MPC非线性和计算量。第一阶段可在SQP迭代内冻结上一轮门控序列，再迭代更新；必须报告迭代次数、超时率和门控序列变化。

#### 3.7.7 敏感度与可解释性验证

不仅比较平均误差，还计算

`S_ij(k)=partial xhat_(k+1,i)/partial x_(k,j)`。

验证内容：

1. 直线阶段横向/横摆组敏感度是否降低；
2. 转弯阶段`vy/r/Fy/左右向货物拉伸载荷`敏感度是否重新激活；
3. 过渡阶段激活是否早于力峰值且无明显抖振；
4. 加速/制动阶段`Fx/前后向货物拉伸载荷`是否占主导；
5. 模型Jacobian与30维物理plant的有限差分局部Jacobian是否方向一致。

不能只展示注意力热图。必须报告分变量组的Jacobian范数、与plant Jacobian的相对误差/余弦相似度，以及门控变化与真实力峰值的时序关系。

#### 3.7.8 多专家证书边界

所有专家必须共享同一lift和共同`P`。若对误差子空间有统一收缩率`rho<1`：

`A_m^T P A_m-rho²P ⪯ 0,  m=1,2,3`，

则对任意凸组合可利用共同`P`范数给出点态收缩上界。这比各专家分别使用不同Lyapunov函数更适合平滑切换。

但这**不能自动证明整个闭环稳定**：还必须包含bilinear输入盒、模型残差、门控估计误差、观测缺失、门控滤波状态、MPC终端集和fallback。若平滑门控使用内部记忆，其滤波状态必须进入增广系统，或给出调度速率界。无法完成时，只保留经验性门控模型，不声称共同稳定性。

#### 3.7.9 多专家专项对比

按以下顺序比较：

1. 固定全状态raw/lifted linear Koopman；
2. 三个分工况独立模型 + test真实标签选择，只作为不可部署的oracle上界；
3. hard-switch Koopman；
4. soft-gated linear Koopman；
5. soft gate +变量组稀疏；
6. 固定单专家MF-IK；
7. `G-MF-IK`完整候选；
8. `G-MF-IK-frozenGate`和`G-MF-IK-noTransition`消融。

场景至少覆盖：直线匀速、加速、减速、正反阶跃转向、单移线、回头弯、直线入弯、弯道出直线、正转向切到反转向。连接器参数失配和网络丢包作为external-test，不用来偷换基础专家定义。

## 4. IRSP与证明的完整处理

### 4.1 推荐证明对象

只对误差子空间矩阵族 `A_delta,eff(u)` 建立共同度量。对控制输入盒顶点 `u_v`，求共同 `P≻0` 和 `rho<1`：

`A_delta,eff(u_v)^T P A_delta,eff(u_v)-rho²P ⪯ 0`。

顶点证书的适用条件、凸性和保守性必须明确写出。随机采样只用于找反例，不能代替证明。

### 4.2 不可行处理

认证失败必须显式返回 `infeasible`，执行：

1. 回滚最近一次已认证模型；
2. 冻结在线更新；
3. 切换到有独立不变集保证的线性/局部控制器；
4. 记录触发次数、持续时间和恢复冲击。

不得再次用 `gamma=0` 表示认证成功。

### 4.3 闭环证明链

完整证明应按以下顺序建立：

1. 从独立验证集给出20步模型残差集合 `W_j`，不能从最终闭环成功日志反推；
2. 用 `W_j`、通信外推误差和执行器误差构造约束收紧；
3. 构造终端控制器、终端集和fallback正不变集；
4. 用 shifted sequence 证明下一时刻递归可行；
5. 从MPC价值函数和终端条件推导下降/ISS界；
6. 对通信模式切换给出dwell-time或共同Lyapunov条件；
7. 最后用日志验证理论条件覆盖率，而不是把日志性质作为定理假设。

如果第3–6步不能严谨完成，应删除 stability theorem，改称经验性可行性/下降监视器。

## 6. 预注册验收门

以下是项目决策门，不是通用科学定律，必须在看最终测试结果前冻结：

### GK2：离线预测价值

- 新数据必须有完全独立test和外部参数失配集，并能按直线、单移线、回头弯及网络激励分层；
- 新状态合同上的raw/lifted linear必须能够输出有限、可复算的1–20步状态和四点受力误差；否则继续修数据合同，不得训练MF-IK；
- `S2-four`必须相对`S1-team`改善至少一项四车横摆或受力预测主要指标，否则不把状态扩维包装成贡献；
- `S3-deform`必须相对`S2-four`改善10–20步货物拉伸载荷/连接力预测，并且CI不跨0；
- `S4-force-in`与`S5-force-out`按独立test误差、参数量和闭环受力选择；若差异小，选更紧凑、共线更少的`S5`；
- `S6-net-in`只有在跨网络分布test优于`S7-net-exo`且不损害clean物理预测时才允许保留；默认采用`S7`；
- soft-gated linear必须在直线、转弯和过渡三个分层test中，相对最佳固定全状态linear至少改善两个分层的10–20步主要NRMSE，且第三个分层不得恶化超过5%；
- 过渡窗口的峰值预测误差和四点力/货物拉伸载荷误差至少降低10%，否则`E-T`没有独立价值；
- 门控必须无专家塌缩：各物理工况的主专家权重排序与预注册规律一致，且soft gate相对hard switch降低切换误差或力冲击；
- Jacobian敏感度必须与plant有限差分方向一致，并相对固定模型降低分变量组Jacobian误差；热图本身不算通过证据；
- 加入变量组稀疏后若只让图更好看而不改善独立test、闭环受力或模型紧凑度，则删除该模块；
- missing-data实验必须区分真实零值和缺失值；mask/AoI消融若无收益，不把观测门控列为贡献；
- MF-IK在独立测试集的10–20步状态NRMSE相对 lifted linear AKE 至少降低10%；
- 四点力或货物拉伸载荷的10–20步NRMSE至少降低10%；
- paired bootstrap 95% CI不跨0，标准化效应量绝对值至少0.5；
- 任一守恒残差不得比物理plant数值容差高一个数量级。

未通过：取消“20步预测明显改进”和bilinear核心贡献。

### GK3：证书价值

- 连续输入盒证书真实可行，不能只通过有限采样；
- bilinear项保留比例不能长期接近0；
- 相比无证书模型，约束违反率或MPC不可行率有统计和实际意义改善；
- 认证/回滚计算满足控制周期，或明确只做离线认证。

未通过：IRSP降级为数值正则化或完全删除。

### GK4：闭环价值

- 相比最佳线性/无多步基线，至少一个预先指定主要指标改善10%；
- 总连接力峰值和货物拉伸载荷P99均不得恶化超过5%；
- 任务完成率不得下降；
- 报告H=20相对H=12的求解时间、超时率和收益；若收益不足以覆盖计算代价，控制器保留H=12。

### GK5：论文决策

- **全部通过**：可把MF-IK作为候选核心贡献，但仍需强基线与理论同行审查；
- **预测通过、证书失败**：保留多步受力感知 Koopman，删除IRSP和稳定性强主张；
- **预测或闭环失败**：采用线性AKE，论文主线改为受力约束的通信质量感知MPC；
- **通信保护仍失败**：不能使用“network-resilient”作无条件标题主张。
