## 0. 先明确目标，避免再次偏离审稿问题

本轮只解决一个主要矛盾：现有方法的20步预测确有收益，但一步预测明显退化；平均收益还掩盖了个别工况退化。

目标不是证明某个预定方法必然最好，而是回答：

1. 训练目标直接包含实际评价的力、内部力和横摆误差后，能否减少短期退化？
2. 在相同模型上加显式退化保护，能否保留多步收益，同时不牺牲短期和局部工况？
3. 如果不能，两种精度要求的冲突发生在哪里，是否需要收缩方法主张？

本轮不增加专家、门控、双线性项、潜变量维度、传感器输入，不重新修改连接器/执行器，不调控制器。不要把预测误差下降写成实际载荷峰值下降，也不要把仿真力解码结果写成实测力。

时间尺度固定：模型采样周期0.02 s；1、5、10、20步分别为0.02、0.10、0.20、0.40 s，40步为0.80 s。“多步预测”不能含糊写成很长时间尺度的稳定性。

## 2. 假设、反证与选择原则

| 编号 | 假设 | 支持它需要什么 | 什么结果否定/限制它 |
|---|---|---|---|
| H1 | 状态训练目标与评价目标错位，导致力和横摆误差未被充分优化 | 指标对齐组相对共同MH对照减小一步、力误差，且保留多步改善 | 对齐后同样退化，或改善全来自舍弃多步能力 |
| H2 | 显式短期/工况保护能减少任务间冲突 | 保护组相对对齐组通过更多保护门，20步仍有净改善 | 只能退回S0精度、约束长期不可行或20步无收益 |
| H3 | 接触边界使小状态误差放大为力误差 | 退化与接触状态错判、力雅可比敏感度有对应关系 | 离边界同样退化，主要问题是全局动力学或时序错位 |
| H4 | 三角残差结构限制了短长期兼顾能力 | 对齐和保护实现均正确，仍存在稳定的精度前沿冲突 | 简单目标修改已在新数据通过，不必新增结构 |

不要求H1—H4全部成立。根据数据保留或否定，禁止把负结果解释成必然支持原路线。

H4只能形成结构瓶颈的候选解释：有限预算、非凸优化和当前正则化同样可能导致失败，不能由一轮训练失败证明“该结构不存在更好解”。T1同时改变了误差分量和RMSE聚合方式，若有效，应归因于这项完整的“评价目标对齐”，不能未经额外消融就归因于单独某个力项。

选择原则：能用较简单方法通过就不用更复杂方法；固定线性S0也是合法胜出者。新增训练约束不是预先宣布的论文创新，创新性必须由归因、比较和独立验证支撑。

## 4. 公式、物理含义及不能证明的内容

### 4.1 保持现有预测结构，不增加专家

本节x、u均指归一化变量；物理输出计算前恢复SI单位。

\[
\eta_0=\phi_\theta(x_k,u_k),\quad
\hat x_{h+1}=A_0\hat x_h+B_0u_{k+h}+b_0+E\eta_h,
\]
\[
\eta_{h+1}=F_c\eta_h+Gu_{k+h}+c,\quad \hat x_0=x_k.
\]

x为47维；u为7维；eta固定16维。分组升维器两个分支各输出8维、隐藏宽16，沿用当前代码，不增加新输入。

重要的行列约定：现有`rollout`使用行向量`eta @ F`，所以本节列向量矩阵`F_c = code_f_matrix.T`。不要为了让代码“长得像公式”直接把现有传播改为`eta @ F.T`；这会改变模型。`full_k_matrix()`用于理论审计时须以有效列矩阵F_c构造，并用一次传播单元测试验证。阻尼旋转的谱半径相同，不代表任意转置都不影响轨迹。

与相同S0开环预测bar x的差为：

\[
\hat x_h-\bar x_h=\sum_{i=0}^{h-1}A_0^{h-1-i}E\eta_i.
\]

因此改善20步累计误差，不自动保证一步修正E eta_0方向正确。对一个给定样本，设真实一步S0残差r=x_{k+1}-bar x_1、修正c_0=E eta_0，任意47×47半正定权矩阵Omega下有（与下一节抓取矩阵W不是同一对象）：

\[
\|r-c_0\|_\Omega^2-\|r\|_\Omega^2=c_0^T \Omega c_0-2r^T\Omega c_0.
\]

右侧小于零才意味着这个加权平方误差改善。这个恒等式不是J_common全局改善证明，不能把平方范数与多个RMSE的加权和混用。

### 4.2 固定物理力解码与内部力

保持原R3力律、单位、符号、参数和抓取矩阵不变；只把可微实现接入损失。

\[
\hat f_h=\mathcal D_{R3}(\hat x_h^{SI};p),\quad
\hat f_{int,h}=P\hat f_h,\quad P=I-W^\dagger W.
\]

p为轨迹对应已知仿真参数；同轨迹S0和全部候选用同一p。参数信息来自模拟器，是条件已知参数的实验，不等于已经证明在线可测或可辨识。

符号和维度：A0为47×47，B0为47×7，b0为47维；E为47×16，F_c为16×16，G为16×7，c为16维；f与f_int均为8维；W为把四点平面力映射到货物平面合力/横摆力矩的3×8矩阵，P为8×8。lambda为55个无量纲经验约束乘子。几何或参数随轨迹变化时，常量缓存必须以params SHA作为键，不能全数据错误共用一套P或力律参数。

训练和评价的力目标必须来自cache的`force_payload_body8[k+h]`与`internal_force8[k+h]`；先验证真实状态经过同一解码器能复原这些目标。不能悄悄改成“解码真实状态的输出”并替换不一致的原始目标。

P用于固定几何的平面力内部成分，验证W f_int接近零。水平平面Fx/Fy、重力方向Fz与拉伸型内部载荷代理分别命名；不从force8推断垂向载荷已获验证。

### 4.3 原损失与指标对齐损失

原MH的主损失：

\[
L_{MH}=\sum_{h\in\{1,5,10,20\}}a_h
\sum_{g=0}^{3}w_g\operatorname{RMSE}_{batch,g}(\hat x_h-x_h)+R(\theta),
\]

a=(0.10,0.20,0.25,0.45)，w=(0.30,0.20,0.20,0.30)。它直接优化状态组误差，和最终的力/内部力加权评价并非同一函数。

对单个窗口定义与当前评价一致的无量纲误差：

\[
j_h=\frac{0.25e_{core,h}+0.20e_{relative,h}+0.20e_{force,h}
+0.15e_{internal,h}+0.10e_{yaw,h}}{0.90}.
\]

core取状态索引0:3；relative取3:47；yaw取[2,21,24,27,30]；force/internal分别是8分量。每个e为按本折拟合集scale归一化后的分量RMSE。必须保留0.90分母，不能误把总权重按1处理。

训练用平滑RMSE：`sqrt(mean(error**2)+eps**2)-eps`，eps=1e-8；相对于精确RMSE误差不超过eps。评价仍用原精确RMSE。eps只用于防零误差梯度问题，不是物理平滑宽度，禁止调大eps来改善得分。

本轮统一采用层次平均：窗口→轨迹→基础样本族→工况。令J_{s,h}为工况s的族等权均值，M_h=(1/12)sum_s J_{s,h}。这样长轨迹和左右双成员不会凭数量占更大权重。旧“工况内窗口等权”继续输出为legacy口径，但不得混入主表。

指标对齐组：

\[
L_{JM}=\sum_h a_h M_h^{train,\varepsilon}+R(\theta).
\]

训练采样使用工况→族→轨迹→窗口的均衡采样，使损失近似上述层次均值；每批每工况21窗，额外4窗的归属按预注册序列轮换。批内先各工况平均，再12工况等权；禁止再叠加旧SB的逆窗口频数权重，造成重复补偿。

### 4.4 保护组：求经验约束，不宣称自动保证泛化

以同折S0为锚，固定拟合集基准M_h^0、J_{s,h}^0。定义：

\[
g_h^{short}=\frac{M_h-M_h^0}{\max(M_h^0,10^{-12})}-0.03,
\qquad h\in\{1,5,10\};
\]
\[
g_{s,h}^{scenario}=\frac{J_{s,h}-J_{s,h}^0}{\max(J_{s,h}^0,0.02)}-0.03,
\quad s=D0\ldots D11,\ h=1,5,10,20.
\]

另对连接力与内部力的全局归一化RMSE，在h=1、20各设5%退化保护，共4项；其分母为`max(对应S0均值,1e-12)`，不能拿J的0.02直接套用。约束总数=3+48+4=55。

保护损失采用明确的有界乘子更新方案：

\[
L_{JG}=L_{JM}+\frac{M_{20}^0}{55}
\sum_{c=1}^{55}\left(\lambda_c\hat g_c+
\frac{\beta}{2}[\hat g_c]_+^2\right),\qquad\beta=1,
\]
\[
\lambda_c^{t+1}=\operatorname{clip}_{[0,20]}
\left(\lambda_c^t+0.5\,g_c^{full\ fit}\right),\qquad\lambda_c^0=0.
\]

- 每500个优化步，用完整拟合集cache窗口精确计算g并更新乘子，禁止用内部选择集/外层目标更新乘子。
- 批内hat g使用同一冻结基准与上述工况均衡估计；乘子更新值可detach，损失中的候选误差不能detach。
- 拟合集、内部选择集、外层集分别用同折S0在各自集合上的误差作对比锚。只有拟合集锚进入训练；内部选择门不能误用拟合集的误差基准，外层锚在冻结模型后计算。
- JG warm与其余方法一致；保护仅在正式阶段开启。乘子、计数器、全拟合集g及其SHA进入检查点。
- 若乘子达到上界，记录为`SATURATED`，不临时提高上界；它只是优化器有限预算下的经验算法，不是严格可行性求解器。
- 若某个S0物理误差低于1e-10，记录近零基线；仍用上述分母并输出绝对误差，不事后换阈值。数值问题先用精确S0回退测试区分。

只要令E=0，该结构能退回同折S0，因而这些“不退化”约束存在基准可行点；但这个可行点的20步改善为0。不能由“存在可行点”推出“必然存在既可行又改善5%的解”。

### 4.5 稳定性与解释性的边界

残差块的r_j=0.995 sigmoid(a_j)<0.995，可以证明残差齐次传播的收缩；有效F_c转置不改变其2范数。给定有界输入：

\[
\|\eta_h\|_2\le r^h\|\eta_0\|_2+
\frac{1-r^h}{1-r}(\|G\|_2u_{max}+\|c\|_2),\quad r=\max_j r_j.
\]

整体K=[[A0,E],[0,F_c]]的谱为A0与F_c谱的并集。但这不控制非正规瞬态放大、不自动保证A0稳定，也不证明MPC递归可行或闭环ISS。必须报告||K^h||、||E||、残差幅值和有限时域发散，不以“结构稳定”掩盖放大现象。

本轮物理可解释性来自：直接保留47维物理状态、已知力律输出、固定内部力投影及分组升维。不要把每个潜模态直接称为某个弹簧固有模态，除非另有频率和参数识别证据。

## 8. 指标、统计与正式验收门

### 8.1 两个符号分开，所有表注明分母

改善率：`I_h=100*(M_h^0-M_h)/max(M_h^0,1e-12)`，正为改善。
工况退化：`D_s,h=100*(J_s,h-J_s,h^0)/max(J_s,h^0,0.02)`，正为退化。
两者不是严格相反数，因为分母不同。程序字段分别用`improvement_pct`、`degradation_pct`，禁止混用better/worse无定义字段。

本轮主统计顺序严格为：每窗口→每轨迹→每基础族→每工况→12工况。五折汇总先拼接各族唯一外层结果，再按该层次聚合；同时另列逐折结果。因为每折归一化来自各自拟合集，报告该差异，并同步给N、rad、m/s等可比较的物理量；不得用混合单位的`state47_rmse_si`作有物理单位的总RMSE。

### 8.2 正式进入V0候选的必要条件

| 门 | 条件 | 依据/范围 |
|---|---|---|
| 身份/权限 | 源码、协议、cache、归一化、S0、检查点可追溯；禁止数据数值读取0 | 证据有效性硬门 |
| 完整性 | 5折、3组和S0全有结果；每折12工况；配对键一致；缺失与重复0 | 不能挑工况 |
| 20步净收益 | 主M20相对同折汇总S0改善≥5%，且≥4/5折改善 | 沿用既定5%研究目标 |
| 短期全局 | h=1/5/10的相对退化各≤3%，不使用0.02下限稀释全局短期门 | 对齐原V0要求 |
| 工况保护 | 12工况×4时域按D_s,h计算均≤3%；逐折和合并均检查 | 本轮预注册强化，不追溯改写旧run裁决 |
| 物理输出 | force/internal归一化RMSE的h=1/5/10/20全局退化均≤5%，逐折与合并均检查 | 不能只靠综合J抵消力退化 |
| D5 | 20步整体和困难窗（冻结start100/120）均值/P95/P99/max退化≤3%，分母max(对应S0统计量,0.02) | 沿用困难工况保护；需报告族数 |

| 推理成本 | batch1 GPU20步中位数<1 ms、P99<2 ms；CPU中位数<5 ms | 沿用任务书工程目标；包含升维、传播及力/内部力解码 |

5%是入围最低门；若达到≥10%且全部保护门通过，可标为较强内部结果。不要要求一定保住原20.08%，因为本轮训练数据/流程更严格；也不能把5%的目标事后降到1%。

推理计时固定CPU线程数、GPU预热200次后测1000次；GPU必须用CUDA events或同步计时，不能直接用异步`perf_counter`低估耗时。数据从CPU到GPU的传输时间另列，同时报告实际部署端到端时间；不能用批量吞吐替代batch1延迟。

### 8.3 bootstrap与不确定性

每次在各工况内对基础样本族有放回抽样，保留该族全部轨迹/窗口；S0与候选复用相同抽样索引。P95/P99按族等权、族内轨迹等权、轨迹内窗口等权形成加权经验CDF，分位数定义为`inf{x: F_weighted(x)>=q}`，max为该合法集合实际最大值；不得把“族均值P99”称为“瞬态误差P99”。D5整体和困难窗各自重新归一化权重，逐折与汇总都报告。bootstrap的95%区间取2000次复算改善率的2.5%和97.5%分位点，使用固定`method=linear`。

内部5折只有5个模型初始化，不等于5个相同全训练集seed。V0以后另做5个全训练seed，不用外层bootstrap冒充模型随机性分析。对非主要比较报告效应与区间，不进行大规模显著性挑选；方法选择会增加乐观偏差，最终声明依赖新数据。

## 10. 失败处理与允许的自我修正

### 10.1 不必每次请示的工程修正

可在本轮授权内处理：路径/BOM/编码、日志flush、参数张量device/dtype、不改变数学的批处理、显式错误提示、原子写入、模块导入隔离、图中文字/单位、读取受保护数据的接口接线。

要求：先复现→保存栈和证据→apply_patch修改→补回归测试→重算源码manifest→从受影响阶段新attempt开始→日志说明。不能修改已冻结的历史产物。

同一工程问题最多两轮修复；再失败保存现场并停止相关阶段。没有失败就不必每个节点人工确认，按任务树自动继续；授权/科学假设/数据边界变化必须停。

### 10.2 明确的问题与处理方向

| 情况 | 先查什么 | 允许处理 | 必须停止/不得操作 |
|---|---|---|---|
| CUDA OOM | 活跃进程、模型副本、图保留、参数缓存 | 减少计算微批；T1可按固定工况计数累积线性加权梯度，正则项只加一次；固定总batch与顺序 | T0的batch-RMSE和T2的约束均值平方不能直接平均微批loss；不能静默改总batch |
| T0/T2需要微批 | batch组RMSE或正违约量平方的非线性聚合 | 先计算全batch充分统计量，再按链式法则第二遍反传，或checkpoint重计算；必须对齐完整batch梯度 | 无等价证明则停，不能把RMSE换成MSE或把整体约束换成微批约束 |
| 物理损失全零梯度 | 无接触、E=0、预测detach、参数缓存串轨迹 | 分开测有接触/无接触；保留状态项提供接触前梯度 | 不能把零梯度自动认定正常；不能改R3力律强造梯度 |
| NaN/Inf | scale近零、sqrt零点、参数越界、步长、decoder | 保存失败batch与模型；先修实现并通过回归 | 禁止过滤NaN、clip预测力、改变阈值或继续训练 |
| 力oracle不一致 | k与k+h错位、SI恢复、坐标、law/params、力正负 | 修接口和已证明的索引错误 | 如涉及原始物理或数据错误，停止学习，另写修复方案 |
| 一步过门而20步无收益 | 约束是否使E接近零；S0是否已经足够好 | 输出精度前沿与E幅值，评价H2失败 | 不放宽一步门，不将回到S0写成创新 |
| 20步有效但一步仍退化 | 活跃/饱和约束、梯度冲突、评估目标对齐 | 当前run只诊断，不改lambda上限/权重 | 不直接进V0，不临时拼ONE前1步+MH后20步 |
| D1修好但D0或其他类变差 | 55约束是否全覆盖；实际采样概率 | 修漏索引/错采样等实现错误并新run | 不能再追加只为D0定制的权重而称预注册实验 |
| T1/T2完全同结果 | 保护未激活还是断梯度/lambda未更新 | 比较约束、梯度与参数，不只看打印loss | 正常不激活时承认保护无额外作用，不制造差异 |
| 投影CPU/GPU不匹配 | 常量device、float64、矩阵尺寸 | 常量缓冲对齐；固定P缓存 | 不移动/覆盖旧decoder，不detach预测 |
| 推理超时 | Python逐窗循环、重复pinv、GPU同步错误 | 固定常量缓存、向量化，数值等价后重测同协议 | 不去掉力解码、不改成大batch吞吐、不删P99 |
| 分折缺工况/数量不符 | family ID、方向成员、plant筛选、字符串排序 | 修元数据与分层算法，冻结新清单 | 不填0或NA当PASS，不借用验证集补足 |
| resume不等价 | 优化器动量、lambda、RNG、采样位置、dtype、代码SHA | 同身份修完整恢复回归后重跑相关阶段 | 不只恢复模型参数并假称续跑 |
| 外层已读后发现实现错误 | 哪些结果/模型受影响，选择是否受结果影响 | 保留污染/作废标签与原因，停止待新协议 | 不覆盖外层CSV，不声称重新划分后又变盲 |
| 模型全过但功能无额外收益 | T1−T0、T2−T1效应与成本 | 选择简单方法、收缩创新声明 | 不把相同数值四舍五入成“更优” |

软件格式修复不是改变物理/学习目标的授权。临时加新专家、扩维、调连接器、换数据分布、增加seed、重设门槛、换ridge、调整本文件lambda/保护比例均属于新实验，需停止并提出新预注册方案。

```powershell
# 读取刚生成的准确run身份；不搜索“最新目录”，也不等待人工输入。
$KgMeta = Get-Content -LiteralPath $KgReceipt -Raw | ConvertFrom-Json
if ($KgMeta.run_tag -ne 'KG_R01' -or -not $KgMeta.run_id) { throw 'Invalid KG receipt' }
$KgRunId = [string]$KgMeta.run_id
& $KgPython (Join-Path $KgSource 'scripts\run_v3t.py') --stage G1 --project-root $KgProject --protocol $KgProtocol --taskbook $KgTaskbook --resume-run $KgRunId
if ($LASTEXITCODE -ne 0) { throw 'KG G1 failed' }

# 在此完成G2代码实现和源码登记；测试失败时不能接着训练。
& $KgPython -m pytest (Join-Path $KgSource 'tests') -q
if ($LASTEXITCODE -ne 0) { throw 'KG tests failed' }
foreach ($KgStage in @('G2','G3','G4','G5')) {
    & $KgPython (Join-Path $KgSource 'scripts\run_v3t.py') --stage $KgStage --project-root $KgProject --protocol $KgProtocol --taskbook $KgTaskbook --resume-run $KgRunId
    if ($LASTEXITCODE -ne 0) { throw "KG stopped at $KgStage" }
}
```

runner还必须校验回执与run_identity中的run_tag、任务书/数据SHA和相应阶段源码SHA一致，不能只校验非空run_id。回执已存在时不得覆盖：若确为同一次运行则用`--resume-run`恢复；否则登记一个新的run_tag及新回执路径。不同阶段源码快照可以因G2实现而新增，但已有受影响训练不能跨源码身份续跑。

精确续跑接口：

```powershell
& $KgPython (Join-Path $KgSource 'scripts\run_v3t.py') --stage G4 --project-root $KgProject --protocol $KgProtocol --taskbook $KgTaskbook --resume-run $KgRunId --resume-incomplete
if ($LASTEXITCODE -ne 0) { throw 'KG resume failed; inspect solutions.md' }
```

`--resume-incomplete`只能跳过已核对complete+SHA的任务，并恢复同身份的last；不得拿它重算并覆盖已查看的外层结果。进程锁包括主机、PID、run_id、启动时间；PID存在且归属不明时不抢锁、不终止进程。

G0/G1/G2以CPU只读审计和测试为主；G3核定实测成本后再跑G4。不能承诺固定几小时完成。输出包含每组训练/监控/解码开销，便于判断方法是否值得。
